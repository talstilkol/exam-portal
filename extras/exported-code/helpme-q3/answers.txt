א. GET / POST / PUT / DELETE
GET    = שליפת מידע בלבד. לא אמור לשנות מידע בשרת.
POST   = יצירת מידע חדש או פעולה שמייצרת רשומה חדשה.
PUT    = עדכון מלא / החלפה מלאה של משאב קיים.
DELETE = מחיקה של משאב קיים.
 
ב. MongoDB — 3 יתרונות ו־2 חסרונות
יתרונות:
1. מבנה גמיש: אפשר לשמור documents בפורמט JSON בלי טבלאות קשיחות.
2. נוח מאוד לעבודה עם JavaScript / Node כי הנתונים דומים לאובייקטים.
3. מתאים למידע שמשתנה מהר ולמערכות שצריכות סקייל גבוה.
חסרונות:
1. פחות מתאים לקשרים מורכבים מאוד בין טבלאות.
2. קל לעשות מודל לא מסודר אם לא מתכננים schema בצורה נכונה.
 
ג. למה React ולא HTML/CSS/JS רגיל?
יתרונות:
1. Components: מפרקים את האתר לחלקים קטנים שניתן להשתמש בהם שוב.
2. State: שינוי מידע מרנדר מחדש את המסך באופן אוטומטי.
3. Router ו־ecosystem גדול: קל לבנות אפליקציה עם כמה עמודים וכלים רבים.
חיסרון:
1. יש עקומת למידה וצריך build tools כמו Vite / npm.
 
ד. Function מול Arrow Function
function רגילה מקבלת this משלה וניתנת ל־hoisting.
arrow function קצרה יותר, לא מקבלת this משלה, ומאוד נוחה ל־callbacks.
 
ה. מה הפונקציה עושה?
const func = (num) => {
  if (num === 1) return 1;
  return num * func(num - 1);
}
זו פונקציה רקורסיבית שמחשבת עצרת factorial.
לדוגמה: func(5) = 5 * 4 * 3 * 2 * 1 = 120.
