1. יסודות TypeScript ▼

Primitive Types - טיפוסים בסיסיים

TypeScript מרחיב את JavaScript עם מערכת טיפוסים סטטית. הנה כל הטיפוסים הבסיסיים:

// טיפוסים בסיסיים
let userName: string = "Alice";
let age: number = 25;
let isActive: boolean = true;
let nothing: null = null;
let notDefined: undefined = undefined;

// any - מבטל את בדיקת הטיפוסים (נמנעים מלהשתמש!)
let anything: any = "hello";
anything = 42;       // OK - אין שגיאה
anything.toFixed(); // OK - אין בדיקה

// unknown - גרסה בטוחה של any
let mystery: unknown = "hello";
// mystery.toUpperCase(); // ERROR! חייבים לבדוק קודם
if (typeof mystery === "string") {
  mystery.toUpperCase(); // OK - אחרי narrowing
}

// void - פונקציה שלא מחזירה ערך
function logMessage(msg: string): void {
  console.log(msg);
}

// never - פונקציה שלעולם לא מסתיימת
function throwError(msg: string): never {
  throw new Error(msg);
}

Type Inference - הסקת טיפוסים

TypeScript יודע להסיק טיפוסים אוטומטית - לא תמיד חייבים לכתוב אנוטציות:

// TS מסיק את הטיפוס בעצמו
let name = "Bob";       // string (מוסק)
let count = 10;        // number (מוסק)
let flag = true;       // boolean (מוסק)

// הסקה בפונקציות - TS מסיק את ערך ההחזרה
function add(a: number, b: number) {
  return a + b; // TS מסיק: number
}

// מתי כן כותבים אנוטציה?
// 1. משתנה שמתחיל ללא ערך
let items: string[];  // חייבים - אחרת TS לא יודע
// 2. פרמטרים של פונקציה
function greet(name: string) {} // חייבים!

Union Types & Literal Types

Union type מאפשר למשתנה להיות אחד מכמה טיפוסים. Literal type מגביל לערכים ספציפיים:

// Union Types - אחד מכמה טיפוסים
let id: string | number;
id = "abc";  // OK
id = 123;    // OK
// id = true; // ERROR!

// Literal Types - ערכים ספציפיים
type Role = "admin" | "user" | "guest";
let userRole: Role = "admin"; // OK
// let userRole: Role = "superuser"; // ERROR!

type Status = "loading" | "success" | "error";
function showStatus(s: Status) {
  switch(s) {
    case "loading": return "Loading...";
    case "success": return "Done!";
    case "error":   return "Failed!";
  }
}

Type Aliases, Optional & Readonly

// Type Alias - שם לטיפוס מורכב
type User = {
  name: string;
  age: number;
  email: string;
};

// Optional property - שדה אופציונלי עם ?
type Profile = {
  name: string;
  age?: number;          // אופציונלי - יכול להיות undefined
  bio?: string;
};

const p1: Profile = { name: "Dan" };              // OK
const p2: Profile = { name: "Dan", age: 30 };    // OK

// Readonly - שדה שלא ניתן לשנות
type Config = {
  readonly id: number;
  readonly apiKey: string;
  debug: boolean;       // ניתן לשנות
};

const config: Config = { id: 1, apiKey: "xyz", debug: true };
// config.id = 2;      // ERROR! readonly
config.debug = false;  // OK
💡 טיפ למבחן ההבדל בין any ל-unknown שאלה קלאסית! any מבטל את כל הבדיקות, unknown מכריח narrowing לפני שימוש. תמיד העדיפו unknown על any.
כלל אצבע: אם TS מסיק נכון, אל תכתבו אנוטציה. אם לא, כתבו.
2. Enums - מניות ▼

Numeric Enums

Enum הוא אוסף של קבועים בעלי שם. ב-numeric enum הערכים הם מספרים:

// Numeric enum - ערכים מספריים אוטומטיים
enum Direction {
  Up,      // 0
  Down,    // 1
  Left,    // 2
  Right    // 3
}

let dir: Direction = Direction.Up;
console.log(dir);           // 0
console.log(Direction[0]);  // "Up" - reverse mapping!

// אפשר לקבוע ערך התחלתי
enum StatusCode {
  OK = 200,
  NotFound = 404,
  ServerError = 500
}

String Enums

ב-string enum כל ערך הוא מחרוזת. קריא יותר אך אין reverse mapping:

// String enum - ערכי מחרוזת
enum Color {
  Red   = "RED",
  Green = "GREEN",
  Blue  = "BLUE"
}

let fav: Color = Color.Blue;
console.log(fav); // "BLUE"

// שימוש ב-enum כטיפוס ובתנאי
function paint(color: Color): string {
  switch (color) {
    case Color.Red:   return "Painting red!";
    case Color.Green: return "Painting green!";
    case Color.Blue:  return "Painting blue!";
  }
}
paint(Color.Red); // "Painting red!"

Enum vs Union Literal

// Option A: Enum
enum Size {
  Small  = "S",
  Medium = "M",
  Large  = "L"
}

// Option B: Union Literal (קל יותר, אין runtime code)
type SizeUnion = "S" | "M" | "L";

// מתי להשתמש בכל אחד?
// Enum: כשצריכים reverse mapping, או ערכים מספריים
// Union: כשרוצים פשטות, ללא קוד נוסף ב-JS output
💡 טיפ למבחן שימו לב ל-Enum שמור ל-runtime (מתקמפל ל-JS אמיתי), בעוד ש-union literal נמחק בקומפילציה.
ב-string enum אין reverse mapping. ב-numeric enum - יש.
3. Tuples - טאפלים ▼

Basic Tuples

Tuple הוא מערך עם אורך קבוע וטיפוסים שונים בכל מיקום:

// Basic Tuple - מערך קבוע
let pair: [string, number] = ["Alice", 25];

console.log(pair[0]); // "Alice" - string
console.log(pair[1]); // 25 - number

// שגיאות:
// pair = ["Alice"];          // ERROR - חסר number
// pair = [25, "Alice"];      // ERROR - סדר לא נכון

// שימוש נפוץ: החזרת כמה ערכים מפונקציה
function getUser(): [string, number] {
  return ["Bob", 30];
}
const [name, userAge] = getUser(); // destructuring

Named Tuples, Optional & Rest

// Named Tuples (TS 4.0+) - שמות לתיעוד
type Point = [x: number, y: number];
const origin: Point = [0, 0];

// Optional Elements
type RGB = [number, number, number, number?]; // alpha אופציונלי
const red: RGB = [255, 0, 0];       // OK
const blue: RGB = [0, 0, 255, 0.5]; // OK

// Rest Elements
type StringAndNums = [string, ...number[]];
const data: StringAndNums = ["grades", 90, 85, 95, 78]; // OK

// readonly tuple
type Coord = readonly [number, number];
const pos: Coord = [10, 20];
// pos[0] = 5; // ERROR! readonly
💡 טיפ למבחן Tuple vs Array: מערך רגיל (number[]) הוא באורך משתנה עם טיפוס אחיד. Tuple הוא באורך קבוע עם טיפוסים שונים בכל מקום.
useState של React מחזיר tuple: [value, setter].
4. Functions - פונקציות ▼

Typed Parameters & Return Types

// פרמטרים וערך החזרה מוטייפים
function add(a: number, b: number): number {
  return a + b;
}

// Arrow function
const multiply = (a: number, b: number): number => a * b;

// פונקציה שמחזירה אובייקט
function createUser(name: string, age: number): { name: string; age: number } {
  return { name, age };
}

Optional, Default & Rest Parameters

// Optional parameter - עם ?
function greet(name: string, title?: string): string {
  if (title) return `Hello, ${title} ${name}`;
  return `Hello, ${name}`;
}
greet("Alice");           // "Hello, Alice"
greet("Alice", "Dr.");  // "Hello, Dr. Alice"

// Default parameter - ערך ברירת מחדל
function power(base: number, exp: number = 2): number {
  return Math.pow(base, exp);
}
power(3);      // 9 (exp=2 by default)
power(3, 3);   // 27

// Rest parameters
function sum(...nums: number[]): number {
  return nums.reduce((total, n) => total + n, 0);
}
sum(1, 2, 3, 4); // 10

Function Type Expressions

// הגדרת טיפוס של פונקציה
type MathOp = (a: number, b: number) => number;

const addOp: MathOp = (a, b) => a + b;
const subOp: MathOp = (a, b) => a - b;

// פונקציה שמקבלת פונקציה כפרמטר (callback)
function calculate(x: number, y: number, op: MathOp): number {
  return op(x, y);
}
calculate(10, 5, addOp); // 15
calculate(10, 5, subOp); // 5

void vs undefined, never

// void - הפונקציה לא מחזירה ערך משמעותי
function logIt(msg: string): void {
  console.log(msg);
  // return undefined; // OK - תקין אבל מיותר
}

// undefined - מחזירה undefined במפורש
function findItem(id: number): string | undefined {
  const items = ["a", "b", "c"];
  return items[id]; // יכול להחזיר undefined
}

// never - לעולם לא מסתיימת (throw / infinite loop)
function fail(msg: string): never {
  throw new Error(msg);
}

// never שימושי ב-exhaustive check
type Shape = "circle" | "square";
function area(shape: Shape) {
  switch (shape) {
    case "circle":  return "circle area";
    case "square":  return "square area";
    default:
      const _never: never = shape; // ERROR if missing case
      return _never;
  }
}
💡 טיפ למבחן void אומר "לא אכפת לנו מערך ההחזרה". never אומר "הפונקציה לעולם לא מסיימת".
פרמטר אופציונלי (?) חייב להיות אחרון! פרמטר עם default לא חייב.
5. Objects & Interfaces ▼

Interface Declaration

// הגדרת interface
interface User {
  id: number;
  name: string;
  email: string;
  isActive: boolean;
}

const user: User = {
  id: 1,
  name: "Alice",
  email: "alice@test.com",
  isActive: true
};

Extending Interfaces

// הרחבת interface
interface Animal {
  name: string;
  age: number;
}

interface Dog extends Animal {
  breed: string;
  bark(): void;
}

const myDog: Dog = {
  name: "Rex",
  age: 5,
  breed: "Labrador",
  bark() { console.log("Woof!"); }
};

// הרחבה מרובה
interface Timestamped {
  createdAt: Date;
  updatedAt: Date;
}

interface Post extends User, Timestamped {
  title: string;
  content: string;
}

Implementing Interfaces in Classes

interface Printable {
  print(): void;
}

interface Loggable {
  log(msg: string): void;
}

class Report implements Printable, Loggable {
  constructor(public title: string) {}

  print(): void {
    console.log(`Report: ${this.title}`);
  }

  log(msg: string): void {
    console.log(`[${this.title}]: ${msg}`);
  }
}

Interface vs Type Alias

// Interface - ניתן להרחבה, declaration merging
interface IUser {
  name: string;
}
interface IUser {  // declaration merging - מתמזגים!
  age: number;
}
// IUser = { name: string; age: number }

// Type - יותר גמיש, unions, tuples, primitives
type ID = string | number;            // union - רק type!
type Pair = [string, number];          // tuple - רק type!
type Callback = () => void;             // function type

// כלל אצבע:
// interface - לאובייקטים ו-classes
// type - ל-unions, tuples, מורכבים

Index Signatures & Intersection Types

// Index Signature - מפתחות דינמיים
interface Dictionary {
  [key: string]: string;
}

const translations: Dictionary = {
  hello: "shalom",
  goodbye: "lehitraot",
  // כל מפתח string עם ערך string
};

// Intersection Types - שילוב טיפוסים
type HasId = { id: number };
type HasName = { name: string };
type Entity = HasId & HasName;  // חייב את שניהם!

const entity: Entity = {
  id: 1,
  name: "Item"
};
💡 טיפ למבחן extends = ירושה (interface מ-interface). implements = class מיישם interface.
& (intersection) = חייבים את הכל. | (union) = אחד מהם.
interface תומך ב-declaration merging, type לא.
6. Generics - גנריקס ▼

Generic Functions

Generics מאפשרים ליצור קוד גמיש שעובד עם טיפוסים שונים בלי לאבד type safety:

// ללא generics - חייבים ליצור פונקציה לכל טיפוס
function firstString(arr: string[]): string { return arr[0]; }
function firstNumber(arr: number[]): number { return arr[0]; }

// עם generics - פונקציה אחת לכל הטיפוסים!
function first<T>(arr: T[]): T {
  return arr[0];
}

first<string>(["a", "b"]);  // "a" (string)
first<number>([1, 2, 3]);  // 1 (number)
first([true, false]);       // true - TS מסיק T = boolean

// identity function
function identity<T>(arg: T): T {
  return arg;
}
const result = identity("hello"); // T = string (מוסק)

Generic Interfaces & Constraints

// Generic Interface
interface ApiResponse<T> {
  data: T;
  status: number;
  message: string;
}

const userRes: ApiResponse<User> = {
  data: { id: 1, name: "Alice", email: "a@b.c", isActive: true },
  status: 200,
  message: "OK"
};

// Generic Constraints - הגבלת T
interface HasLength {
  length: number;
}

function logLength<T extends HasLength>(item: T): void {
  console.log(item.length);
}

logLength("hello");     // 5 - string has length
logLength([1, 2, 3]); // 3 - array has length
// logLength(42);       // ERROR! number has no length

Built-in Utility Types

interface User {
  id: number;
  name: string;
  email: string;
  age: number;
}

// Partial<T> - כל השדות הופכים לאופציונליים
type UpdateUser = Partial<User>;
// = { id?: number; name?: string; email?: string; age?: number }

function updateUser(id: number, data: Partial<User>) {
  // data can have any subset of User fields
}
updateUser(1, { name: "New Name" }); // OK!

// Required<T> - כל השדות הופכים לחובה
type FullUser = Required<User>;

// Pick<T, K> - בוחרים שדות ספציפיים
type UserPreview = Pick<User, "name" | "email">;
// = { name: string; email: string }

// Omit<T, K> - מוציאים שדות ספציפיים
type CreateUser = Omit<User, "id">;
// = { name: string; email: string; age: number }

// Record<K, V> - יוצרים אובייקט עם מפתחות וערכים
type Scores = Record<string, number>;
const grades: Scores = {
  math: 95,
  english: 88,
  science: 92
};

// Readonly<T> - כל השדות readonly
type FrozenUser = Readonly<User>;
💡 טיפ למבחן Partial - שימושי ל-update functions. Omit - שימושי ליצירה (בלי id שנוצר אוטומטית).
Pick vs Omit: Pick בוחר מה לקחת, Omit בוחר מה להוציא.
Record<string, T> = אובייקט עם מפתחות מחרוזת וערכי T.

Typed State (useState)

import { useState } from "react";

const [count, setCount] = useState(0);          // number
const [text, setText] = useState("");            // string

const [items, setItems] = useState<string[]>([]);

// בדיקת null לפני גישה
if (user) {

}

Typed Events

import React from "react";

function LoginForm() {
  const [email, setEmail] = useState("");

  // ChangeEvent - לשינוי ב-input
  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    setEmail(e.target.value);
  };

  // FormEvent - לשליחת טופס
  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    console.log("Submitted:", email);
  };

  // MouseEvent - ללחיצה
  const handleClick = (e: React.MouseEvent<HTMLButtonElement>) => {
    console.log("Clicked at", e.clientX, e.clientY);
  };

  // SelectEvent - ל-select element
  const handleSelect = (e: React.ChangeEvent<HTMLSelectElement>) => {
    console.log("Selected:", e.target.value);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input value={email} onChange={handleChange} />
      <button onClick={handleClick}>Submit</button>
    </form>
  );
}

Typed Refs & Children

import { useRef, useEffect } from "react";

function AutoFocusInput() {
  // useRef עם טיפוס HTML element
  const inputRef = useRef<HTMLInputElement>(null);

  useEffect(() => {
    // חייבים לבדוק null!
    if (inputRef.current) {
      inputRef.current.focus();
    }
  }, []);

  return <input ref={inputRef} />;
}

// Children type - קומפוננטה שעוטפת תוכן
interface CardProps {
  title: string;
  children: React.ReactNode;  // כל תוכן React תקין
}

function Card({ title, children }: CardProps) {
  return (
    <div className="card">
      <h2>{title}</h2>
      {children}
    </div>
  );
}

// React.FC - סגנון ישן (חלק נמנעים ממנו)
// הוא מוסיף children אוטומטית ומשנה את הטיפוס
const OldCard: React.FC<CardProps> = ({ title, children }) => {
  return <div>{title} - {children}</div>;
};
// למה נמנעים: FC משנה את defaultProps ואת return type
// עדיף: function component רגילה עם Props interface
💡 טיפ למבחן את האירועים הכי חשוב לזכור:
React.ChangeEvent<HTMLInputElement> - שינוי ב-input
React.FormEvent<HTMLFormElement> - שליחת טופס
React.MouseEvent<HTMLButtonElement> - לחיצה
useState<Type | null>(null) - כשמתחילים מ-null חייבים generic!
useRef<HTMLElement>(null) - תמיד לבדוק .current לפני שימוש.
8. תרגול מהשיעורי בית ▼

Book Type with Enum Genres (שיעורי בית TS 1)

// Enum ל-genres
enum Genre {
  Fiction     = "FICTION",
  NonFiction  = "NON_FICTION",
  Science     = "SCIENCE",
  History     = "HISTORY",
  Fantasy     = "FANTASY"
}

// Interface לספר
interface Book {
  readonly id: number;
  title: string;
  author: string;
  genre: Genre;
  pages: number;
  isAvailable: boolean;
  rating?: number;  // 1-5, אופציונלי
}

// יצירת ספרים
const books: Book[] = [
  {
    id: 1,
    title: "Dune",
    author: "Frank Herbert",
    genre: Genre.Fantasy,
    pages: 412,
    isAvailable: true,
    rating: 5
  },
  {
    id: 2,
    title: "Sapiens",
    author: "Yuval Harari",
    genre: Genre.History,
    pages: 443,
    isAvailable: false
  }
];

// פונקציות עזר
function getBooksByGenre(books: Book[], genre: Genre): Book[] {
  return books.filter(b => b.genre === genre);
}

function getAvailableBooks(books: Book[]): Book[] {
  return books.filter(b => b.isAvailable);
}

function addBook(books: Book[], newBook: Omit<Book, "id">): Book[] {
  const id = books.length + 1;
  return [...books, { ...newBook, id }];
}

User Types with Unions (שיעורי בית TS 1)

// תפקידי משתמש
type UserRole = "admin" | "editor" | "viewer";

// טיפוס בסיסי
interface BaseUser {
  id: number;
  name: string;
  email: string;
  role: UserRole;
}

// Discriminated union - טיפוס שונה לכל role
interface AdminUser extends BaseUser {
  role: "admin";
  permissions: string[];
  canDelete: boolean;
}

interface EditorUser extends BaseUser {
  role: "editor";
  department: string;
}

interface ViewerUser extends BaseUser {
  role: "viewer";
}

type AppUser = AdminUser | EditorUser | ViewerUser;

// Narrowing with discriminated union
function getUserInfo(user: AppUser): string {
  switch (user.role) {
    case "admin":
      return `Admin ${user.name} - ${user.permissions.join(", ")}`;
    case "editor":
      return `Editor ${user.name} from ${user.department}`;
    case "viewer":
      return `Viewer ${user.name}`;
  }
}

Budget Manager (שיעורי בית React + TS 2)

// Transaction Types
enum TransactionType {
  Income  = "INCOME",
  Expense = "EXPENSE"
}

enum Category {
  Food      = "FOOD",
  Transport = "TRANSPORT",
  Housing   = "HOUSING",
  Salary    = "SALARY",
  Other     = "OTHER"
}

interface Transaction {
  readonly id: number;
  type: TransactionType;
  category: Category;
  amount: number;
  description: string;
  date: string;
}

// React Component with full typing
import { useState } from "react";

function BudgetManager() {
  const [transactions, setTransactions] =
    useState<Transaction[]>([]);

  // הוספת טרנזקציה - Omit<T,"id"> כי id נוצר אוטומטית
  const addTransaction = (data: Omit<Transaction, "id">) => {
    const newTx: Transaction = {
      ...data,
      id: Date.now()
    };
    setTransactions(prev => [...prev, newTx]);
  };

  // חישוב יתרה
  const getBalance = (): number => {
    return transactions.reduce((sum, tx) => {
      return tx.type === TransactionType.Income
        ? sum + tx.amount
        : sum - tx.amount;
    }, 0);
  };

  // סינון לפי קטגוריה
  const filterByCategory = (cat: Category): Transaction[] => {
    return transactions.filter(tx => tx.category === cat);
  };

  // טיפול בטופס
  const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    addTransaction({
      type: TransactionType.Expense,
      category: Category.Food,
      amount: 50,
      description: "Groceries",
      date: new Date().toISOString()
    });
  };

  return (
    <div>
      <h1>Balance: {getBalance()}</h1>
      {transactions.map(tx => (
        <div key={tx.id}>
          {tx.description}: {tx.amount}
        </div>
      ))}
    </div>
  );
}
💡 טיפ למבחן דפוס חוזר במבחן: Omit<Type, "id"> ליצירת אובייקטים חדשים (בלי id שנוצר אוטומטית).
Discriminated Union (כמו role או type) - מאפשר ל-TS לדעת בדיוק איזה interface יש ב-switch.
תמיד לרשום useState<Type[]>([]) כשמתחילים ממערך ריק עם טיפוס מורכב.
