🧠 הסיפור של סבתא

נכנסת למסעדה — את רואה תפריט, שולחנות, עיצוב יפה. זה ה־Frontend.
הזמנת אוכל — המלצר רץ למטבח עם הפתק. זה ה־Server.
השף מבשל — לוקח חומרי גלם מהמזווה, מכין מנה. זה ה־Backend.
המזווה — שם שמורות החביתות, הקמח, הירקות. זה ה־Database.
המלצר חוזר — מביא לך את הצלחת. הסיבוב הסתיים — זה Request → Response.

🧠 טריקי זיכרון לרמת מבחן

קודי HTTP בעברית: 1=מדבר, 2=הצליח (כן!), 3=זרק אותך לכתובת אחרת, 4=אתה טעית, 5=השרת התרסק.
הקודים שצריך לדעת בעל פה: 200 OK · 201 Created · 301 Moved · 401 Unauthorized · 403 Forbidden · 404 Not Found · 500 Server Error.
PUT vs PATCH: PUT = שורף הכל ובונה מחדש. PATCH = עורך רק את מה שצריך. PATCH = "טלאי".
401 vs 403: 401 = "מי אתה?" (לא מזוהה). 403 = "אתה לא רשאי" (מזוהה אבל אסור).
JWT = "תעודת זהות" שאי אפשר לזייף. השרת בודק את החתימה ויודע שזה אמיתי.
CRUD ↔ HTTP: Create=POST · Read=GET · Update=PUT/PATCH · Delete=DELETE.

📐 THEORY

CAP Theorem

משפט CAP
במערכת מבוזרת אפשר רק 2 מתוך 3: Consistency, Availability, Partition tolerance.

🧠 טריקים לזכירה (לראיון Senior)

Monolith → Microservices. אבל לא מתחילים ממיקרו! מתחילים ממונולית, מפצלים כשכואב.
CAP: "C-A-P — בחר 2". בנקים בוחרים CP. רשתות חברתיות AP.
Cache Hierarchy: Browser → CDN → Redis → DB. ככל שיותר קרוב למשתמש — יותר מהיר.
Sync vs Async: HTTP=סינכרוני (מחכה לתשובה). Queue=אסינכרוני (זורק וממשיך).
Horizontal vs Vertical Scaling: Vertical=שרת חזק יותר (גבול). Horizontal=עוד שרתים (אינסוף).
GraphQL = "תפריט שאתה בונה". REST = מנות מוכנות. GraphQL = שאל מה שתרצה.
