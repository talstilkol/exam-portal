1. תמונת פתרון מהירה

נושאSERVER
מה צריך להגיששרת Express עם מערך shipments[] בזיכרון, ולידציה מלאה, status enum, וסינון לפי משקל.
אסטרטגיית פתרון1. לפתוח Express. 2. express.json() + cors(). 3. מערך shipments[] + nextId. 4. GET/POST/PUT/DELETE. 5. ולידציה + enum בדיקה. 6. 201 ביצירה, 204 במחיקה, 404 כשלא נמצא.

2. פירוק מלא לסעיפים ותתי סעיפים

יש לבנות שרת Express לניהול הזמנות משלוח. לכל משלוח: sender, receiver, weight (Number, חיובי), destination, status (ברירת מחדל: "pending"). Routes: GET /shipments (כל המשלוחים), POST /shipments (הוספה עם ולידציה), PUT /shipments/:id/status (עדכון סטטוס — pending/shipped/delivered בלבד), DELETE /shipments/:id, GET /shipments/heavy?min=X (סינון לפי weight ≥ min).
מה צריך לעשות: לבנות כל route בנפרד, עם ולידציה מלאה על כל קלט.
למה: מבחן Express בודק דיוק בסטטוסים, enum validation ו-query param המרה.
מה לוודא: req.query.min הוא string — חייבים Number(). POST מחזיר 201. PUT ו-DELETE מחזירים 404 אם לא נמצא.

✅ QA ו־Debug — מה לוודא לפני שמגישים

1. express.json()חובה לפני routes שקוראים req.body.
2. Number()req.query.min הוא string — להמיר לפני השוואה.
3. Enumstatus חייב להיות pending/shipped/delivered.
4. 201/204POST → 201, DELETE → 204, שגיאה → 400/404.
5. 404PUT/DELETE — לבדוק שהמשלוח קיים לפני עדכון.
6. /heavyלוודא שה-route מוגדר לפני /shipments/:id.

⚠️ כל האפשרויות לעשות טעויות — כדי שלא תטעי

  • לשים GET /shipments/heavy לפני GET /shipments/:id — אחרת "heavy" יתפס כ-:id
  • req.query.min הוא string — חייבים Number() לפני השוואה
  • POST מחזיר 201 (לא 200)
  • DELETE מחזיר 204 (לא 200)
  • enum validation על status — לא לשכוח לבדוק שהערך ברשימה המותרת
  • PUT ו-DELETE מחזירים 404 אם id לא קיים

⚠️ טעויות מורחבות שלא ליפול בהן

  • לא לשכוח app.use(express.json()) לפני routes שקוראים req.body.
  • לא לשכוח cors() אם הלקוח רץ מפורט אחר.
  • req.params.id הוא string — להשתמש ב-Number() לפני השוואה עם id מספרי.
  • req.query.min הוא string — להמיר ב-Number() לפני פעולות מתמטיות.
  • GET /shipments/heavy חייב להיות מוגדר לפני GET /shipments/:id.
  • POST → 201, DELETE → 204, עדכון → 200, שגיאה → 400, לא נמצא → 404.
  • enum validation — תמיד לבדוק שהסטטוס ברשימה המותרת לפני עדכון.
  • לא לשכוח app.listen(PORT). בלי זה השרת לא עולה.
