1. תמונת פתרון מהירה

נושאSERVER
מה צריך להגיששרת Express עם מערך rates[] של {type, value}, CRUD מלא + GET /convert?from&to&amount.
אסטרטגיית פתרון1. express.json() + cors(). 2. rates[] עם ערכי ברירת מחדל. 3. GET/POST/PUT/DELETE /rates. 4. GET /convert עם המרה + ולידציות. 5. Number() על query params. 6. בדיקת from !== to ו-toRate.value !== 0.

2. פירוק מלא לסעיפים ותתי סעיפים

יש לבנות שרת Express לניהול תעריפי מטבע. לכל תעריף: type (String, אנגלית בלבד), value (Number, חיובי). Routes: GET /rates, POST /rates (ולידציה + 201), PUT /rates/:type (404 אם לא נמצא), DELETE /rates/:type (404 אם לא נמצא), GET /convert?from=X&to=Y&amount=Z (חישוב המרה).
מה צריך לעשות: לממש CRUD מלא + המרת מטבע עם ולידציות מרובות.
למה: נקודות על ולידציה נכונה — type אנגלית, value חיובי, from !== to, 404 אם מטבע לא נמצא.
מה לוודא: amount הוא string מה-query — Number() חובה. חלוקה באפס — toRate.value !== 0.

✅ QA ו־Debug — מה לוודא לפני שמגישים

1. express.json()חובה לפני routes שקוראים req.body.
2. Number(amount)query params הם strings — להמיר.
3. from !== toאסור להמיר מטבע לעצמו.
4. 404 למטבעPUT/DELETE/convert → 404 אם type לא קיים.
5. חלוקה באפסלבדוק toRate.value !== 0 לפני חישוב.
6. type regexאנגלית בלבד: /^[A-Za-z]+$/

⚠️ כל האפשרויות לעשות טעויות — כדי שלא תטעי

  • amount מ-query string הוא string — חובה Number() לפני השוואה או חישוב
  • from ו-to חייבים להיות שונים — בדיקת from.toUpperCase() === to.toUpperCase()
  • toRate.value === 0 → חלוקה באפס → תוצאה: Infinity — לבדוק לפני החישוב
  • 404 אם fromRate או toRate לא נמצאו במערך
  • type אנגלית בלבד — regex /^[A-Za-z]+$/ בדיקה ב-POST
  • toUpperCase() על type בכל חיפוש ויצירה — לא לשכוח
  • POST מחזיר 201, DELETE מחזיר 200 עם הודעה

⚠️ טעויות מורחבות שלא ליפול בהן

  • לא לשכוח app.use(express.json()) לפני routes שקוראים req.body.
  • req.query.* תמיד string — להמיר ב-Number() לפני חישובים.
  • toUpperCase() — כל חיפוש וכל יצירה חייבים להיות אחידים.
  • חלוקה באפס: (x * fromRate) / toRate.value — אם toRate.value == 0, JavaScript מחזיר Infinity (לא שגיאה). לבדוק ידנית.
