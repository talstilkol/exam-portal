5. Master Plan להמשך שיפור

  1. רמת מקור: מעבר ידני מול תמונות ה־PDF בשאלות שה־OCR שלהן חלש.
  2. רמת קוד: להוציא כל פתרון React/Node לתיקיית פרויקט אמיתית ולהריץ npm run build.
  3. רמת בדיקות: להוסיף לכל שאלת JavaScript מערך בדיקות קלט/פלט.
  4. רמת UX: להוסיף חיפוש חופשי באינדקס לפי שם מבחן/שאלה/טכנולוגיה.
  5. רמת למידה: להוסיף “סדר עבודה ב־30 דקות” לכל שאלה.

6. מגבלות הבדיקה

הבדיקה בוצעה כבדיקה סטטית של HTML/CSS/קישורים/תוכן/הסברי קוד, ובדיקת Syntax בסיסית לקוד כאשר מדובר בקוד ולא בתשובה תאורטית. לא הורץ build לכל פרויקט React/Node כתיקייה עצמאית.
