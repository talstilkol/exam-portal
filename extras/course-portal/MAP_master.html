⚠️ קיר המלכודות — 10 הטעויות הקריטיות

אם אתה זוכר רק 10 דברים מכל החומר — אלה הם.

🪤 1

typeof null === "object"

זה לא bug שלך — זו "תכונה" של JS משנת 95.

✅ השתמש: val === null
🪤 2

NaN === NaN → false

NaN הוא היחיד ב-JS שלא שווה לעצמו.

✅ השתמש: Number.isNaN(x)
🪤 3

const אינו immutable

const נועל את הכתובת, לא את התוכן.
const arr=[1]; arr.push(2) — חוקי!

🪤 4

{} === {} → false

אובייקטים מושווים לפי כתובת בזיכרון, לא תוכן.

🪤 5

Mutation ב-React State

arr.push(x) לא יגרום לרינדור!

✅ setArr([...arr, x])
🪤 6

Stale Closure ב-useEffect

שכחת dependency → ה-Effect "תקוע" עם ערך ישן.

🪤 7

var ב-for loop

for(var i=0;i<3;i++) setTimeout(()=>log(i)) — מדפיס 3,3,3.

✅ השתמש ב-let
🪤 8

slice vs splice

slice לא משנה את המקור — splice כן!
arr.splice(0,1) מוחק מ-arr.

🪤 9

Promise.all עם reject

אם אחד נכשל — כל ה-Promise.all נכשל (Fail-fast).

✅ Promise.allSettled מחזיר את כולם
🪤 10

target vs currentTarget

e.target = הילד שלחצו עליו
e.currentTarget = ההורה שמאזין

👑 11 כללי הזהב

תזכרו את אלה — הם יחסכו לכם נקודות במבחן.

1️⃣

תמיד === ולא ==

השוואה מדויקת בלי casting אוטומטי

2️⃣

Functional update לסטייט

setCount(c => c+1)

3️⃣

keys לפי id, לא index

אחרת — בעיות במחיקה/הוספה

4️⃣

Cleanup ב-useEffect

בכל subscribe → return unsubscribe

5️⃣

try/catch בכל async

אחרת — unhandled rejection 💥

6️⃣

Validation לפני save

בלי בדיקות = bugs ב-DB

7️⃣

אסור Mutation

תמיד spread או structuredClone

8️⃣

Type ל-useState

useState<User>(...)

9️⃣

Conditional rendering ברור

{cond && <X/>} או ternary
