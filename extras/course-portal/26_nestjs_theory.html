📦 Nest.js קושי 5

▾
👵 סבתא
ארגון עסק גדול: מנהל, מחלקות, עובדים — כל אחד יודע תפקידו.
🪖 חייל
Framework Node.js עם TypeScript-first, decorators, DI container. רץ מעל Express. CLI: nest new, nest g module/controller/service.
🎓 סטודנט
מושפע מ-Angular: modules, decorators, DI. שכבות: Module → Controller (HTTP) → Service (logic). Built-in: validation, guards, interceptors, exception filters.
Nest נותן מבנה קבוע לפרויקטים גדולים: איפה routes, business logic ו-data.
@Module({ controllers: [TasksController], providers: [TasksService] }) export class TasksModule {}
לחשוב ש-Nest מחליף Node — Nest רץ על Node, מוסיף שכבת ארגון.

📁 module קושי 5

▾
👵 סבתא
מחלקה בבית-חולים: ילדים, נשים, לב — כל אחת עם הרופאים שלה.
🪖 חייל
@Module decorator: imports, controllers, providers, exports. AppModule = root. Feature modules: TasksModule, UsersModule.
🎓 סטודנט
providers זמינים רק בתוך המודול, אלא אם exported. @Global() — זמין בכל מקום. Module = bounded context ב-DDD.
@Module({ imports: [AuthModule], controllers: [TasksController], providers: [TasksService], exports: [TasksService], }) export class TasksModule {}
לזרוק את כל ה-providers ב-AppModule במקום modules לפי domain.

🎮 controller קושי 4

▾
🪖 חייל
@Controller('tasks') = prefix /tasks. Decorators: @Get(), @Post(), @Put(), @Patch(), @Delete(). Params: @Body, @Param, @Query.
🎓 סטודנט
Controllers: HTTP layer only. Status codes default: POST=201, others=200. Error handling דרך throwing — exception filters תופסים.
@Controller('tasks') export class TasksController { constructor(private readonly tasksService: TasksService) {} @Get() findAll() { return this.tasksService.findAll(); } @Post() create(@Body() dto: CreateTaskDto) { return this.tasksService.create(dto); } @Get(':id') findOne(@Param('id', ParseIntPipe) id: number) { return this.tasksService.findOne(id); } }
לכתוב business logic כבדה בתוך controller — delegate ל-service.

⚙️ service & provider קושי 5

▾
👵 סבתא
הטבח שיודע מתכונים. הקבלן מקבל הזמנה — הוא מבשל.
🪖 חייל
@Injectable() class = provider. Nest מנהל instance singleton. Service = business logic.
🎓 סטודנט
Provider scopes: DEFAULT (singleton), REQUEST (per-request), TRANSIENT (per-injection). Custom providers: useValue, useFactory.
@Injectable() export class TasksService { private tasks: Task[] = []; findAll(): Task[] { return this.tasks; } create(dto: CreateTaskDto): Task { const task = { id: Date.now(), ...dto }; this.tasks.push(task); return task; } }
ליצור service ידנית עם new במקום לתת ל-Nest להזריק דרך DI.

💉 Dependency Injection קושי 6

▾
👵 סבתא
לפתוח מקרר ולמצוא שכל המוצרים כבר שם — הילדים לא צריכים לקנות בעצמם.
🪖 חייל
Constructor מצהיר תלויות → Nest container מספק. constructor(private tasksService: TasksService)
🎓 סטודנט
IoC + DI. TypeScript metadata → reflect-metadata. Circular DI → forwardRef. Benefits: testability, flexibility, composability.
@Controller('tasks') export class TasksController { constructor(private readonly tasksService: TasksService) {} // Nest injects! } // בבדיקות: const moduleRef = await Test.createTestingModule({ providers: [TasksService, { provide: TasksRepo, useValue: mockRepo }], }).compile();
להסתיר תלות בתוך קובץ עם new — קשה לבדוק ולהחליף.

✅ DTO + ValidationPipe קושי 6

▾
🪖 חייל
DTO = Data Transfer Object. Class עם class-validator decorators. ValidationPipe בודק לפני handler.
🎓 סטודנט
Options: whitelist (strip extras), forbidNonWhitelisted (reject), transform (instance creation). PartialType, OmitType, PickType מ-mapped-types.
// dto: export class CreateTaskDto { @IsString() @MinLength(3) title: string; @IsOptional() @IsBoolean() done?: boolean; } // main.ts: app.useGlobalPipes(new ValidationPipe({ whitelist: true, forbidNonWhitelisted: true }));
להגדיר DTO בלי להפעיל ValidationPipe — הבדיקות לא רצות.

🛡️ Guard | 🔧 Pipe | 🔀 Interceptor | ⚠️ Exception Filter קושי 6

▾

Guard — מחליט: מותר / אסור

@Injectable() export class JwtAuthGuard implements CanActivate { canActivate(context: ExecutionContext): boolean { const req = context.switchToHttp().getRequest(); return verifyToken(req.headers.authorization); } } // Usage: @UseGuards(JwtAuthGuard)

Pipe — ממיר / מאמת קלט

// Built-in: ParseIntPipe, ParseUUIDPipe, DefaultValuePipe @Get(':id') findOne(@Param('id', ParseIntPipe) id: number) { ... }

Interceptor — עוטף handler (לפני + אחרי)

@Injectable() export class LoggingInterceptor implements NestInterceptor { intercept(ctx: ExecutionContext, next: CallHandler): Observable { const start = Date.now(); return next.handle().pipe(tap(() => console.log(`${Date.now()-start}ms`))); } }

Exception Filter — תופס errors → HTTP response

@Catch(NotFoundException) export class NotFoundFilter implements ExceptionFilter { catch(exception: NotFoundException, host: ArgumentsHost) { const res = host.switchToHttp().getResponse(); res.status(404).json({ error: exception.message }); } }
לבלבל interceptor עם guard: guard מחליט אם להמשיך, interceptor עוטף פעולה שממשיכה.
