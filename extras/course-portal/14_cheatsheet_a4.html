JavaScript

JS יסודות

  • var/let/const: var=Function+Hoisting, let/const=Block Scope
  • == vs ===: == עושה Coercion, === גם בודק סוג
  • Array: map(מחזיר מערך), filter(תנאי), reduce(ערך)
  • Destructuring: const {name, age=20} = user
  • Spread: [...arr] / {...obj} — עותק רדוד
  • Optional Chaining: obj?.prop?.sub
  • Nullish: a ?? 'default' — רק null/undefined
Async

אסינכרוניות

  • Event Loop: Sync → Microtasks (Promise) → Macrotasks (setTimeout)
  • Promise: Pending → Fulfilled / Rejected
  • async/await: עוטף Promise, חובה try/catch
  • Promise.all: מקביל, נכשל אם אחד נכשל
  • Promise.allSettled: ממתין לכולם, לא נכשל
  • Closure: פונקציה שזוכרת את סביבת יצירתה
React

React Core & Hooks

  • Virtual DOM: Diffing — מרנדר רק מה שהשתנה
  • useState: set(prev => prev+1) למניעת Stale Closure
  • useEffect: [] = Mount, [x] = עדכון, חובה return cleanup
  • useMemo/useCallback: Cache ערך/פונקציה
  • useRef: לא גורם לרינדור, DOM ו-timer refs
  • State Immutable: לא לשנות ישירות — {...obj, x:1}
Node.js

Node.js & Express

  • Node: Single Thread + Event Loop = לא חוסם
  • Middleware: (req,res,next) => { next() }
  • CORS: app.use(cors()) לפני routes
  • Routes: router.get/post/put/delete
  • .env: סודות — לא לגיט! process.env.VAR
  • Error: res.status(400).json({message})
MongoDB

MongoDB & Mongoose

  • NoSQL: מסמכי BSON, אין סכמה קשיחה
  • Schema/Model: Schema=מבנה, Model=פעולות
  • Embed vs Ref: קטן=Embed, גדל=ObjectId + populate()
  • CRUD: findMany, findById, create, findByIdAndUpdate, findByIdAndDelete
  • Validation: required:true, unique:true
  • pre('save'): לפני שמירה — Bcrypt hash
Security

Auth & Security

  • JWT: Header.Payload.Signature — Stateless, לא ב-DB
  • XSS: JS זדוני → טוקן ב-HttpOnly Cookie
  • CSRF: ניצול Cookie → SameSite / Anti-CSRF
  • Bcrypt: Hash+Salt, compare(plain, hash)
  • 401: לא מזוהה (Authentication)
  • 403: מזוהה אבל אין הרשאה (Authorization)
TypeScript

TypeScript

  • Type vs Interface: Type=כל מה שאפשר, Interface=אובייקטים (extends)
  • Union: string | number
  • Optional: name?: string
  • Generics: function fn<T>(x: T): T
  • Utility: Partial<T>, Required<T>, Pick<T,K>, Omit<T,K>
  • Type Guard: typeof x === 'string'
CSS

CSS / Flex / Grid

  • Flex: display:flex; justify-content; align-items
  • Grid: grid-template-columns: repeat(3,1fr)
  • Box Model: content + padding + border + margin
  • Position: relative=מקום מקורי, absolute=להורה, fixed=viewport
  • Z-index: עובד רק על positioned elements
  • Media Query: @media (max-width:768px)
DevOps

Docker & DevOps

  • Image vs Container: Image=תבנית, Container=instance רץ
  • Dockerfile: FROM, WORKDIR, COPY, RUN, CMD
  • docker-compose: מריץ כמה שירותים יחד
  • Volumes: שמירת נתונים מחוץ לcontainer
  • CI/CD: Push → Test → Build → Deploy אוטומטי
  • .env בdocker: env_file: .env ב-compose
Git

Git Workflow

  • Flow: Working → add → Stage → commit → Local → push
  • Branch: git checkout -b feature/x
  • Merge vs Rebase: Merge=commit מיזוג, Rebase=היסטוריה ישרה
  • PR: Pull Request = code review לפני merge
  • .gitignore: node_modules/, .env, dist/
  • Conflict: ידנית — קבל/דחה שינויים
Algorithms

אלגוריתמים נפוצים

  • Palindrome: str === str.split('').reverse().join('')
  • Fibonacci: f(n)=f(n-1)+f(n-2), base: f(0)=0, f(1)=1
  • Dedup: [...new Set(arr)]
  • Count Chars: obj[c] = (obj[c]||0) + 1
  • Complexity: O(1) const, O(n) linear, O(n²) nested loop
  • Binary Search: O(log n) — מערך ממוין בלבד
Patterns

Error Handling & Patterns

  • try/catch/finally: finally רץ תמיד
  • Custom Error: class MyError extends Error
  • Express: (err,req,res,next) => res.status(500)
  • Memory Leak: setInterval ב-useEffect בלי cleanup
  • Singleton: מחלקה עם instance אחד בלבד
  • SOLID: Single Responsibility, Open/Closed
