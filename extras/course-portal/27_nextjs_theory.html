🖥️ Server Component vs Client Component קושי 5

▾
צירServer Component 🖥️Client Component 💻
סימוןברירת מחדל"use client" בראש הקובץ
מורשהawait db.query, secrets, FSuseState, useEffect, onClick, browser APIs
אסורuseState, useEffect, onClickDB access, secrets
Bundle JS0 bytes לדפדפןנשלח כ-JS bundle
Hydrationלא מתבצעתכן
S // server component — ברירת מחדל export default async function OrdersPage() { const orders = await db.orders.findMany(); // ✅ ישירות לDB return <OrdersTable orders={orders} />; } C // client component "use client"; export function Counter() { const [count, setCount] = useState(0); return <button onClick={() => setCount(c => c+1)}>{count}</button>; }
להפוך כל עץ ל-"use client" — מבטל יתרון RSC, מגדיל bundle.
RSC = 0 JS לדפדפן + גישה ישירה ל-DB בלי לחשוף secrets.
