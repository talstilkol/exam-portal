📜 SQL — יסודות קושי 3

▾
👵 סבתא
כמו לבקש מהספרנית: "תני לי כל ספרי רובין הוד". SQL = שפת הבקשה לבסיס הנתונים.
🪖 חייל
4 פעולות: SELECT (קריאה), INSERT (יצירה), UPDATE (עדכון), DELETE (מחיקה).
🎓 סטודנט
Declarative: מתאר מה רוצים, לא איך. Query planner מחליט על execution plan (scan, index, JOIN order).
SELECT id, title, price FROM courses WHERE active = true ORDER BY title LIMIT 10;
להניח ש-ORM מבטל צורך ב-SQL — ORM מייצר SQL, בעיות ביצועים נפתרות דרך הבנת השאילתה.

🐘 PostgreSQL + טבלאות קושי 4

▾
CREATE TABLE users ( id integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY, email text NOT NULL UNIQUE, name text NOT NULL, created_at timestamptz NOT NULL DEFAULT now() ); CREATE TABLE courses ( id integer GENERATED ALWAYS AS IDENTITY PRIMARY KEY, title text NOT NULL, active boolean NOT NULL DEFAULT true );
טיפים
text במקום varchar(255), numeric לכסף, timestamp WITH TIME ZONE, audit columns created_at/updated_at
PostgreSQL יתרונות
MVCC, WAL, JSON/JSONB, full-text search, PostGIS, window functions, CTEs רקורסיביות
PostgreSQL = קובץ JSON גדול — החוזק הוא schema, constraints, JOIN ו-query planner.

🔗 Relations + Foreign Key + JOIN קושי 5

▾
סוג קשרמימושדוגמה
1:1FK + UNIQUEuser ↔ profile
1:NFK בילדuser → posts
N:Mjunction tablestudents ↔ courses דרך enrollments
CREATE TABLE enrollments ( student_id integer NOT NULL REFERENCES students(id), course_id integer NOT NULL REFERENCES courses(id), enrolled_at timestamptz DEFAULT now(), PRIMARY KEY (student_id, course_id) ); -- JOIN query SELECT s.email, c.title FROM enrollments e JOIN students s ON s.id = e.student_id JOIN courses c ON c.id = e.course_id WHERE c.active = true;
JOIN סוגמחזיר
INNER JOINרק התאמות בשני הצדדים
LEFT JOINכל השמאל + התאמות (NULL אם אין)
CROSS JOINCartesian product — כפולה ⚠️
שכפול מידע במקום קשר — גורם לעדכונים כפולים ונתונים סותרים.
JOIN ללא ON — Cartesian product = millions of rows!

📋 Migration קושי 5

▾
מה זה
שינוי גרסתי ומבוקר ב-schema: יצירה/הוספה/שינוי עמודה, index, constraint.
כלים
Prisma migrate, Drizzle Kit, Knex, Flyway. כל migration רץ פעם אחת.
-- migration: הוספת column ALTER TABLE courses ADD COLUMN slug text; -- backfill UPDATE courses SET slug = lower(replace(title, ' ', '-')) WHERE slug IS NULL; -- לאחר backfill — הוסף constraint ALTER TABLE courses ALTER COLUMN slug SET NOT NULL; ALTER TABLE courses ADD CONSTRAINT courses_slug_key UNIQUE (slug);
DROP COLUMN מיידי — קוד ישן עוד רץ במקביל. Expand-contract pattern.
שינוי schema ישיר ב-production בלי migration מסודרת.

⚡ Transaction + ACID קושי 6

▾
ACID
Atomicity · Consistency · Isolation · Durability
מהות
קבוצת פעולות שמצליחות יחד או נכשלות יחד — לא מצב חלקי.
BEGIN; UPDATE accounts SET balance = balance - 100 WHERE id = 1; UPDATE accounts SET balance = balance + 100 WHERE id = 2; COMMIT; -- או ROLLBACK אם יש שגיאה -- Prisma transaction: await prisma.$transaction([ prisma.account.update({ where: { id: 1 }, data: { balance: { decrement: 100 } } }), prisma.account.update({ where: { id: 2 }, data: { balance: { increment: 100 } } }), ]);
לעדכן כמה טבלאות בלי transaction — inconsistency אחרי שגיאה באמצע.
UPDATE/DELETE ללא WHERE — כל הטבלה מושפעת!
