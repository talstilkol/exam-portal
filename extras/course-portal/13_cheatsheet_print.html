Cheat Sheet - Full Stack Development (להדפסה)

1. JavaScript Core & ES6

  • let/const vs var: var הוא Function Scoped (hoisted כ-undefined), let/const הם Block Scoped (TDZ).
  • == vs ===: === בודק גם סוג (Type). == עושה Type Coercion. null == undefined // true.
  • Closures: פונקציה 'זוכרת' את ה-Lexical Scope שלה גם כשהיא רצה מחוץ לו. סכנת Memory Leaks.
  • Arrow Functions: אין להן this משלהן (יורשות מהסביבה), אי אפשר לקרוא להן עם new.
  • Copy (Reference vs Value): Primitives עוברים ב-Value. Objects/Arrays ב-Reference.
    Shallow Copy: {...obj}. Deep Copy: JSON.parse(JSON.stringify(obj)) או structuredClone(obj).

2. React & Hooks

  • useState: מחזיר [value, setter]. ה-setter הוא אסינכרוני. בעדכון תלוי-מצב קודם להשתמש ב-Callback: setCount(c => c+1).
  • useEffect: useEffect(() => { ... return cleanup; }, [deps]).
    מערך ריק [] = פעם אחת ב-Mount. בלי מערך = כל רינדור.
  • useMemo & useCallback: useMemo שומר ערך חישוב (Value), useCallback שומר רפרנס לפונקציה (Function ref) כדי למנוע רינדורים מיותרים.
  • Virtual DOM: ריאקט שומר עץ בזיכרון, מבצע Diffing (Reconciliation) ורק אז משנה את ה-Real DOM (Batched Updates).
  • Key Prop: חובה במיפוי רשימות כדי לעזור לריאקט לזהות שינויים באופן מדויק.

3. HTML & CSS

  • Specificity: Inline > ID (1,0,0) > Class (0,1,0) > Tag (0,0,1).
  • Box Model: Content, Padding, Border, Margin. box-sizing: border-box כולל פדינג וגבול ברוחב הכולל.
  • Positioning: relative (נשאר ב-flow, יחסי לעצמו), absolute (יוצא מה-flow, יחסי ל-relative הראשון), fixed (יחסי למסך), sticky (עד גלילה).
  • Flexbox: Container (display:flex), Main Axis (justify-content), Cross Axis (align-items).

4. TypeScript

  • Interfaces vs Types: Interface לרוב לאובייקטים, תומך ב-Declaration Merging. Types תומכים ב-Unions/Intersections.
  • Generics <T>: "משתנה" של Type המועבר לפונקציה כדי להפוך אותה לדינמית תוך שמירה על Type Safety.

5. Asynchronous JS

  • Event Loop: Call Stack (Sync) ➔ Microtask Queue (Promises) ➔ Macrotask Queue (setTimeout/Events). Microtasks קודמים להכל.
  • Promises: States: Pending, Fulfilled, Rejected.
    Promise.all([p1,p2]): מחכה לכולם, קורס אם 1 נופל.
    Promise.allSettled(): תמיד מחכה לכולם.
  • async/await: Syntactic sugar מעל Promises. חובה try/catch לטיפול בשגיאות.

6. Node.js & Express

  • Node: Single-threaded, Non-blocking I/O (בזכות libuv).
  • Express Middleware: פונקציה (req, res, next). חובה לקרוא ל-next() או להחזיר response.
    שגיאות: פונקציה עם 4 פרמטרים (err, req, res, next) תתפס רק ב-Error Handler.
  • CORS: הגנת דפדפן לבקשות בין דומיינים. דורש app.use(cors()) בשרת.

7. DB: MongoDB & Mongoose

  • SQL vs NoSQL: NoSQL (Mongo) - מסמכים BSON, סכימה גמישה (Collections). SQL - טבלאות קשיחות (ACID).
  • Mongoose Schema: new mongoose.Schema({ name: {type: String, required: true, unique: true} }).
  • Relations (Populate): ב-Schema: type: mongoose.Schema.Types.ObjectId, ref: 'User'. ב-query: .populate('user').

8. Security & Auth (JWT)

  • JWT (JSON Web Token): Header.Payload.Signature. ה-Payload קריא לכולם! ال-Signature מגן משינויים.
  • XSS (Cross-Site Scripting): הזרקת סקריפט זדוני. פתרון: React escapes inputs אוטומטית.
  • CSRF: גניבת סשן. פתרון: SameSite: Strict או CSRF Tokens.

9. SQL & PostgreSQL

  • Relational DB: טבלאות מוגדרות מראש, קשרים חזקים (Foreign Keys). מבטיח עקביות (ACID).
  • JOIN: שילוב נתונים מכמה טבלאות לפי מפתח משותף (INNER JOIN, LEFT JOIN).
  • Prisma ORM: מאפשר עבודה Type-Safe מול SQL בעזרת פקודות JS במקום שאילתות RAW.

10. Nest.js Architecture

  • Controllers: אחראים על ניתוב בקשות HTTP (GET/POST) וקבלת קלט.
  • Providers/Services: מחזיקים את הלוגיקה העסקית. מוזרקים דרך Dependency Injection.
  • Modules: קופסאות שמאגדות Controllers ו-Providers יחד סביב דומיין מסוים (למשל UsersModule).

11. AI Engineering

  • Vercel AI SDK: מפשט עבודה עם מודלים, מאפשר Streaming קל משרת ללקוח.
  • RAG (Retrieval-Augmented Gen): חיפוש ידע רלוונטי (וקטורים) ושליחתו כ-Context למודל. מונע Hallucinations.
  • Tool Calling: נותן למודל לבחור כלי מהשרת, אך השרת מבצע בפועל. דורש Authorization קפדני בקוד.
