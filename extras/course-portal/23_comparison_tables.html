🧠 קלסטר 1 — זיכרון, משתנים ומצביעים קושי 8

הסיפור ב-45 שניות: ב-JS יש שני אזורי זיכרון: Stack (קטן, מסודר, מהיר — לערכים פשוטים) ו-Heap (גדול, אקראי — ל-objects). כל משתנה גר ב-Stack. האם הוא מחזיק ערך? → By Value. האם הוא מחזיק כתובת? → By Reference.

💻 קוד מוכיח — Loop Closure

// var — כולם רואים i הסופי for (var i = 0; i < 3; i++) setTimeout(() => console.log(i), 0); // Output: 3, 3, 3 ← BUG // let — per-iteration scope for (let i = 0; i < 3; i++) setTimeout(() => console.log(i), 0); // Output: 0, 1, 2 ✅

🚫 Anti-patterns נפוצים

בעיה: const arr = []; arr = [1,2] → TypeError
למה: const נועל pointer, לא תוכן. arr.push(1) OK — שינית Heap.
בעיה: let copy = obj; — זה pointer copy!
תיקון: let copy = {...obj} (shallow) / structuredClone(obj) (deep)

🧠 Mnemonic

Stack = שולחן הפתקיות שלך. Heap = המחסן. var = רוח רפאים מ-1995. const = שומר מפתח, לא מה שיש בכספת.

📝 שאלות מבחן צפויות

מה יודפס? var x=1; {var x=2;} console.log(x)→ 2 (var לא כפוף ל-block)
מה יודפס? let x=1; {let x=2;} console.log(x)→ 1 (let block-scoped)
למה const arr=[]; arr.push(3) עובד?→ const נועל pointer ב-Stack, לא תוכן ה-Heap
