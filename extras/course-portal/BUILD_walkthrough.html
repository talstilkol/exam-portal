📦 Models — Schema של User + Task

מגדירים מבנה הנתונים ב-DB. כולל hash של סיסמה ב-pre-save hook.

⏱ 20 דק' 0/2 ▶
3.1 צור server/src/models/User.ts
משתמש עם email+password+name. סיסמה מוצפנת אוטומטית עם bcrypt.
💻 הצג קוד דוגמה
server/src/models/User.ts
import mongoose, { Schema } from 'mongoose';
import bcrypt from 'bcryptjs';

const userSchema = new Schema({
  email: { type: String, required: true, unique: true },
  password: { type: String, required: true, minlength: 6 },
  name: { type: String, required: true }
}, { timestamps: true });

userSchema.pre('save', async function(next) {
  if (!this.isModified('password')) return next();
  this.password = await bcrypt.hash(this.password, 10);
  next();
});

userSchema.methods.comparePassword = function(plain: string) {
  return bcrypt.compare(plain, this.password);
};

export default mongoose.model('User', userSchema);
למה pre-save? אם מישהו משתמש ב-User.create() או user.save() — bcrypt רץ אוטומטית. אי אפשר "לשכוח".
🔐 בקרא על bcrypt 💻 ראה במלואו ב-IDE
3.2 צור server/src/models/Task.ts
משימה עם title+status. הקשר ל-User דרך ref.
💻 הצג קוד דוגמה
server/src/models/Task.ts
import mongoose, { Schema } from 'mongoose';

const taskSchema = new Schema({
  title: { type: String, required: true, maxlength: 200 },
  status: { type: String, enum: ['active', 'done'], default: 'active' },
  user: { type: Schema.Types.ObjectId, ref: 'User', required: true }
}, { timestamps: true });

export default mongoose.model('Task', taskSchema);
מה זה ref: 'User'? כמו foreign key ב-SQL. מאפשר אחר כך Task.find().populate('user') — מקבלים את כל פרטי המשתמש בתוצאה.

🚂 Auth Routes — Register + Login

מאפשרים למשתמשים להירשם ולהתחבר. מחזירים JWT.

⏱ 25 דק' 0/2 ▶
4.1 צור middleware/auth.ts
בודק token בכל בקשה מוגנת.
💻 הצג קוד דוגמה
server/src/middleware/auth.ts
import { Request, Response, NextFunction } from 'express';
import jwt from 'jsonwebtoken';

declare global {
  namespace Express {
    interface Request { userId?: string; }
  }
}

export function authMiddleware(req: Request, res: Response, next: NextFunction) {
  const header = req.headers.authorization;
  if (!header?.startsWith('Bearer ')) {
    return res.status(401).json({ error: 'Token required' });
  }
  try {
    const payload = jwt.verify(header.slice(7), process.env.JWT_SECRET!) as { userId: string };
    req.userId = payload.userId;
    next();
  } catch {
    res.status(401).json({ error: 'Invalid token' });
  }
}
🔐 JWT Flow מלא 💻 middleware/auth.ts
4.2 צור routes/auth.ts
POST /register + POST /login. שניהם מחזירים JWT.
💻 הצג קוד דוגמה
server/src/routes/auth.ts
import { Router } from 'express';
import jwt from 'jsonwebtoken';
import User from '../models/User.js';

const router = Router();

router.post('/register', async (req, res) => {
  const { email, password, name } = req.body;
  if (await User.findOne({ email })) {
    return res.status(409).json({ error: 'Email taken' });
  }
  const user = await User.create({ email, password, name });
  const token = jwt.sign({ userId: user.id }, process.env.JWT_SECRET!, { expiresIn: '7d' });
  res.json({ token, user: { id: user.id, email, name } });
});

router.post('/login', async (req, res) => {
  const { email, password } = req.body;
  const user: any = await User.findOne({ email });
  if (!user || !(await user.comparePassword(password))) {
    return res.status(401).json({ error: 'Bad credentials' });
  }
  const token = jwt.sign({ userId: user.id }, process.env.JWT_SECRET!, { expiresIn: '7d' });
  res.json({ token, user: { id: user.id, email: user.email, name: user.name } });
});

export default router;
⚠️ אבטחה: תמיד אותה הודעת שגיאה ל-"user not found" ול-"wrong password". אחרת תוקף יודע אילו אימיילים קיימים!

5.1 צור routes/tasks.ts
כל ה-routes מוגנים. תמיד מסננים { user: req.userId }!
💻 הצג קוד דוגמה
server/src/routes/tasks.ts
import { Router } from 'express';
import Task from '../models/Task.js';
import { authMiddleware } from '../middleware/auth.js';

const router = Router();
router.use(authMiddleware);

router.get('/', async (req, res) => {
  const tasks = await Task.find({ user: req.userId }).sort({ createdAt: -1 });
  res.json(tasks);
});

router.post('/', async (req, res) => {
  const task = await Task.create({ ...req.body, user: req.userId });
  res.status(201).json(task);
});

router.put('/:id', async (req, res) => {
  const task = await Task.findOneAndUpdate(
    { _id: req.params.id, user: req.userId }, req.body, { new: true }
  );
  res.json(task);
});

router.delete('/:id', async (req, res) => {
  await Task.deleteOne({ _id: req.params.id, user: req.userId });
  res.status(204).end();
});

export default router;
⚠️ אבטחה קריטית: כל endpoint חייב { user: req.userId }. אחרת משתמש יכול לראות/לערוך משימות של אחרים!

💻 הצג קוד דוגמה
client/src/api/client.ts
const BASE = 'http://localhost:3000/api';

async function request<T>(path: string, options: RequestInit = {}): Promise<T> {
  const token = localStorage.getItem('token');
  const res = await fetch(`${BASE}${path}`, {
    ...options,
    headers: {
      'Content-Type': 'application/json',
      ...(token && { Authorization: `Bearer ${token}` }),
      ...options.headers,
    },
  });
  if (!res.ok) throw new Error((await res.json()).error);
  return res.status === 204 ? (null as T) : res.json();
}

export const api = {
  get:    <T>(p: string) => request<T>(p),
  post:   <T>(p: string, b: unknown) => request<T>(p, { method: 'POST', body: JSON.stringify(b) }),
  put:    <T>(p: string, b: unknown) => request<T>(p, { method: 'PUT', body: JSON.stringify(b) }),
  delete: <T>(p: string) => request<T>(p, { method: 'DELETE' }),
};
6.2 צור hooks/useAuth.ts
Custom hook לניהול login/logout + token.
💻 הצג קוד דוגמה
client/src/hooks/useAuth.ts
import { useState, useCallback } from 'react';
import { api } from '../api/client';

export function useAuth() {
  const [token, setToken] = useState<string | null>(
    () => localStorage.getItem('token')
  );

  const login = useCallback(async (email: string, pw: string) => {
    const data: any = await api.post('/auth/login', { email, password: pw });
    localStorage.setItem('token', data.token);
    setToken(data.token);
  }, []);

  const logout = useCallback(() => {
    localStorage.removeItem('token');
    setToken(null);
  }, []);

  return { token, login, logout };
}

💻 הצג קוד דוגמה

import { Routes, Route, Navigate } from 'react-router-dom';
import { useAuth } from './hooks/useAuth';
import Login from './pages/Login';
import Dashboard from './pages/Dashboard';

function PrivateRoute({ children }: any) {
  const { token } = useAuth();
  return token ? children : <Navigate to="/login" />;
}

export default function App() {
  return (
    <Routes>
      <Route path="/login" element={<Login />} />
      <Route path="/" element={<PrivateRoute><Dashboard /></PrivateRoute>} />
    </Routes>
  );
}

7.1 דף Login
Form עם controlled inputs. preventDefault + try/catch.
💻 הצג קוד דוגמה
client/src/pages/Login.tsx
import { useState } from 'react';
import { useNavigate } from 'react-router-dom';
import { useAuth } from '../hooks/useAuth';

export default function Login() {
  const [email, setEmail] = useState('');
  const [pw, setPw] = useState('');
  const [err, setErr] = useState('');
  const { login } = useAuth();
  const nav = useNavigate();

  const handle = async (e: any) => {
    e.preventDefault();
    try { await login(email, pw); nav('/'); }
    catch (e: any) { setErr(e.message); }
  };

  return (
    <form onSubmit={handle} className="max-w-sm mx-auto p-6">
      <h1 className="text-2xl font-bold mb-4">Login</h1>
      {err && <div className="text-red-500">{err}</div>}
      <input value={email} onChange={(e) => setEmail(e.target.value)} className="border p-2 w-full" />
      <input type="password" value={pw} onChange={(e) => setPw(e.target.value)} className="border p-2 w-full mt-2" />
      <button className="bg-blue-500 text-white p-2 w-full mt-3">Login</button>
    </form>
  );
}
