🏆 11 כללי זהב לציון 100

1

תמיד === ולעולם לא ==

💻 הצג קוד דוגמה
// ❌ if (x == null) // ✅ if (x === null || x === undefined) // או if (x == null) // רק זה מותר (בודק null + undefined)
2

functional update בכל שינוי state שתלוי בקודם

💻 הצג קוד דוגמה
// ❌ setCount(count + 1); // ✅ setCount(prev => prev + 1); // ❌ setItems([...items, newItem]); // ✅ setItems(prev => [...prev, newItem]);
3

key={item.id} ולא key={index}

💻 הצג קוד דוגמה
// ❌ אם הרשימה משתנה — באגים! {items.map((item, i) => <li key={i}>...</li>)} // ✅ {items.map(item => <li key={item.id}>...</li>)}
4

cleanup בכל useEffect שיש בו subscription

💻 הצג קוד דוגמה
useEffect(() => { const id = setInterval(tick, 1000); return () => clearInterval(id); // ✅ חובה }, []);
5

try/catch בכל async + status codes נכונים

💻 הצג קוד דוגמה
app.post('/api/users', async (req, res) => { try { if (!req.body.name) { return res.status(400).json({ error: 'name required' }); } const user = await User.create(req.body); res.status(201).json(user); // ✅ 201 לCreate } catch (err) { res.status(500).json({ error: err.message }); } });
6

validation לפני שמירה

💻 הצג קוד דוגמה
// בFrontend if (!name.trim()) return alert('שם חובה'); if (age < 0 || age > 120) return alert('גיל לא תקין'); // בBackend if (!email || !email.includes('@')) { return res.status(400).json({ error: 'אימייל לא תקין' }); }
7

אובייקטים — תמיד spread, לא mutate

💻 הצג קוד דוגמה
// ❌ user.age = 31; setUser(user); // ✅ setUser({ ...user, age: 31 }); // ❌ items.push(newItem); setItems(items); // ✅ setItems([...items, newItem]);
8

CORS + JSON middleware — לא לשכוח!

💻 הצג קוד דוגמה
app.use(cors()); app.use(express.json()); // חובה ל-POST!
9

useState עם type ב-TypeScript

💻 הצג קוד דוגמה
// ❌ TS ינחש never[] const [items, setItems] = useState([]); // ✅ const [items, setItems] = useState<Item[]>([]);
10

conditional rendering פשוט וקריא

💻 הצג קוד דוגמה
// ✅ Early return לטעינה ושגיאה if (loading) return <Spinner />; if (error) return <Error message={error} />; if (!data) return <Empty />; return <MainContent data={data} />;
11

שמות משתנים ברורים ובאנגלית

💻 הצג קוד דוגמה
// ❌ const x = users.filter(u => u.a > 18); // ✅ const adults = users.filter(user => user.age > 18);

⚠️ טעויות נפוצות שמורידות נקודות

הטעויות הכי גדולות שמורידות 5-10 נקודות לכל אחת:

בקוד JS

  • שכחתי await — הקוד ממשיך לפני שהבקשה הסתיימה
  • splice במקום filter — splice משנה את המקור!
  • == במקום === — type coercion יוצר באגים מסתוריים
  • שכחתי return ב-arrow function — {...} דורש return
  • JSON.parse על null — תמיד תבדוק if (raw)

ב-React

  • state mutation — user.age = 31; setUser(user)
  • missing key ברשימות
  • useState בתוך תנאי — אסור!
  • useEffect בלי deps — רץ אינסוף
  • שכחתי e.preventDefault() בטופס
  • controlled input בלי onChange — לא נותן להקליד
  • fetch ב-render במקום ב-useEffect

ב-Backend

  • שכחתי app.use(express.json()) — req.body undefined
  • שכחתי app.use(cors()) — Frontend לא יכול להתחבר
  • status codes לא נכונים — POST שמחזיר 200 במקום 201
  • חסר try/catch ב-async — שרת קורס
  • שכחתי await על Mongoose
  • סיסמאות בpalintext — תמיד bcrypt!

בTypeScript

  • any בכל מקום — TS מאבד משמעות
  • שכחתי type ב-useState
  • אסרציות שגויות (as) — מסתיר באגים
  • Optional fields שצריכים להיות חובה

בהגשה

  • הגשה עם node_modules — קובץ ענק!
  • חסר README עם הוראות הרצה
  • השארתי .env בHGashir — סודות חשופים
  • console.logs בכל מקום
  • קוד מתויג כ-TODO
