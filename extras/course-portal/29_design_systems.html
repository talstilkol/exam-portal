🎨 Design Systems — Tailwind CSS, shadcn/UI, Radix UI

🌊 Tailwind CSS — Utility-First

▾
👵 סבתא
במקום לכתוב "כחול כהה, גדול, עם רווח" בקובץ נפרד — כותבים ישירות על האובייקט: "blue-900 text-xl p-4".
🪖 חייל
Utility classes: bg-blue-500 text-white px-4 py-2 rounded-lg hover:bg-blue-600. בנוי על design tokens — spacing, colors, typography.
🎓 סטודנט
JIT compiler: רק classes בשימוש ב-bundle. Config: tailwind.config.js לcustom tokens. Dark mode: class strategy / media.
<!-- Tailwind component --> <button class="bg-violet-600 hover:bg-violet-700 text-white font-medium px-4 py-2 rounded-lg transition-colors duration-200 focus:outline-none focus:ring-2 focus:ring-violet-500"> שמור </button> <!-- Dark mode --> <div class="bg-white dark:bg-gray-900 text-gray-900 dark:text-white">
hex/px ידניים בכל מקום — חוסר עקביות. השתמש ב-design tokens של Tailwind.
className ארוכות ad-hoc לכל שימוש — עדיף cva/cn לvariants.

🧩 shadcn/UI — Copy-Paste Components

▾
🪖 חייל
shadcn/UI = לא npm package. npx shadcn-ui add button מעתיק קוד לפרויקט. קומפוננטות שלך, שולטות בהן במלואן.
🎓 סטודנט
בנוי על Radix UI (behavior) + Tailwind (styling) + cva (variants). כל קומפוננטה = קובץ בתיקיית components/ui.
# התקנה: npx shadcn-ui@latest init npx shadcn-ui@latest add button dialog form # שימוש: import { Button } from "@/components/ui/button" <Button variant="destructive" size="sm">מחק</Button> <Button variant="outline">ביטול</Button>
shadcn = npm package שמגיע מחוץ — זה קוד שמועתק לתוך הפרויקט שלך.

⬡ Radix UI — Accessible Primitives

▾
🪖 חייל
Radix = בלוקי בנייה unstyled לUI: Dialog, DropdownMenu, Tooltip, Select. מטפל ב-focus trap, keyboard nav, ARIA.
🎓 סטודנט
Headless components: behavior ללא styling. מחבר: Radix behavior + Tailwind styling = shadcn/UI.
import * as Dialog from "@radix-ui/react-dialog"; function Modal() { return ( <Dialog.Root> <Dialog.Trigger asChild> <button>פתח</button> </Dialog.Trigger> <Dialog.Portal> <Dialog.Overlay className="fixed inset-0 bg-black/50" /> <Dialog.Content className="fixed top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2 bg-white rounded-lg p-6 shadow-xl"> <Dialog.Title>כותרת</Dialog.Title> <Dialog.Close>✕</Dialog.Close> </Dialog.Content> </Dialog.Portal> </Dialog.Root> ); }
modal מ-div פשוט — ללא focus trap, Esc key, ARIA. השתמש ב-Radix Dialog.

🎯 cva — Class Variance Authority

▾
מה זה
כלי להגדיר variants לקומפוננטה: size, color, state — בצורה type-safe ועקבית.
import { cva } from "class-variance-authority"; const buttonVariants = cva( "inline-flex items-center rounded-md font-medium transition-colors", // base { variants: { variant: { default: "bg-violet-600 text-white hover:bg-violet-700", outline: "border border-gray-300 bg-transparent hover:bg-gray-100", destructive: "bg-red-600 text-white hover:bg-red-700", }, size: { sm: "h-8 px-3 text-sm", md: "h-10 px-4", lg: "h-12 px-6 text-lg", }, }, defaultVariants: { variant: "default", size: "md" }, } ); // שימוש: <button className={buttonVariants({ variant: "outline", size: "sm" })}>
variant ללא defaultVariants — קומפוננטה לא צפויה כשלא מעבירים prop.

🛠️ cn() + Design Tokens + Patterns

▾
// cn() — כלי לחיבור classNames עם override import { clsx } from "clsx"; import { twMerge } from "tailwind-merge"; export function cn(...inputs) { return twMerge(clsx(inputs)); } // שימוש: <div className={cn("px-4 py-2 bg-white", isActive && "bg-violet-600", className)} /> // asChild pattern — Radix <Button asChild> <Link href="/dashboard">Dashboard</Link> {/* Button wraps Link */} </Button>
