🗂 עץ המערכת

שכבות Full Stack

המערכת מתחלקת לשכבות. כל שכבה עושה עבודה אחרת, כמו צוותים שונים באותו בניין. לחצו על שכבה כדי לראות מה היא עושה.

📱 Frontend
המסך שהמשתמש רואה. כאן נמצאים React, קומפוננטות, כפתורים, טפסים, CSS, state ו־fetch. Frontend לא נוגע ישירות ב־Database; הוא שולח בקשות ל־Backend.

Import / Export

חשוב להפריד בין תקשורת רשת לבין ייבוא קבצים. fetch מדבר עם שרת. import מביא קוד מקובץ אחר בפרויקט.

טבלת Export / Import

קובץ מה הוא מייצא? מי מייבא אותו? למה?
Header.jsx קומפוננטת Header App.jsx כדי להציג תפריט/כותרת קבועה
productsApi.js פונקציות getProducts, addProduct עמודי React כדי לשלוח בקשות לשרת
productRoutes.js Router app.js כדי לחבר כתובת API לשרת
productController.js פונקציות Controller productRoutes.js כדי לבצע את הלוגיקה של הבקשה
Product.js Model productController.js כדי לדבר עם MongoDB
כלל סבתא:
import = להביא קובץ מהפרויקט.
export = לאפשר לקובץ אחר להשתמש בי.
fetch = לדבר עם שרת דרך האינטרנט.

📱 Frontend — דוגמת קוד

React
main.jsx → מדליק את האפליקציה 
import React from "react";
import ReactDOM from "react-dom/client";
import App from "./App.jsx";

ReactDOM
  .createRoot(document.getElementById("root"))
  .render(<App />);
productsApi.js → מדבר עם השרת 
export async function getProducts() {
  const res = await fetch("/api/products");
  return res.json();
}

export async function addProduct(product) {
  const res = await fetch("/api/products", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(product)
  });

  return res.json();
}

🧠 Backend — דוגמת קוד

Express
app.js → מחבר Middleware ו־Routes 
import express from "express";
import cors from "cors";
import productRoutes from "./routes/productRoutes.js";

const app = express();

app.use(cors());
app.use(express.json());

app.use("/api/products", productRoutes);

export default app;
productRoutes.js → מפנה ל־Controller 
import express from "express";
import {
  getProducts,
  createProduct,
  deleteProduct
} from "../controllers/productController.js";

const router = express.Router();

router.get("/", getProducts);
router.post("/", createProduct);
router.delete("/:id", deleteProduct);

export default router;

🍽️ משל המסעדה

אסוציאטיבי וקל
Frontend = מלצר
המלצר מדבר עם הלקוח, מציג תפריט, מקבל הזמנה — אבל הוא לא נכנס למחסן ולא מבשל לבד.

Backend = מטבח
המטבח מקבל הזמנה, בודק שהיא הגיונית, מבקש מצרכים מהמחסן, ומחזיר מנה.

Database = מחסן
המחסן לא מדבר עם לקוחות. הוא רק שומר ומחזיר מידע למטבח.

🚨 טעויות נפוצות

לא ליפול כאן
Frontend לא אמור לייבא Model של MongoDB.
Database לא מדבר ישירות עם המשתמש.
Export לא שולח מידע ללקוח — הוא רק מאפשר Import.
Route ב־React הוא לא אותו דבר כמו Route ב־Express.
Frontend מציג ומפעיל fetch.
Backend מקבל בקשות ומחזיר JSON.
Database שומר ומחזיר Documents.
DevOps מריץ, פורס ומחבר סביבה.
