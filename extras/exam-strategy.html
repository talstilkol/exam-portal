▼ 📐 אסטרטגיית JavaScript — Q2
1

קראו את השאלה פעמיים

הבינו: מה הקלט? מה הפלט? מה הדוגמה מראה? הריצו את הדוגמה בראש.

2

כתבו function signature

function solve(arr, target) { } — שם ברור, פרמטרים לפי הדרישה.

3

ולידציית קלט

if (!Array.isArray(arr)) throw ... — בדקו סוג, ריקות, ערכים לא חוקיים.

4

מימוש

אל תחפשו פתרון אלגנטי — פתרון שעובד > פתרון יפה. השתמשו בלולאות רגילות.

5

edge cases

בדקו: מערך ריק, מספר שלילי, אפס, ערך אחד בלבד, כפילויות.

Math.abs() למספרים שליליים! String(num).length לא עובד על שליליים בגלל ה-minus.
return ולא console.log! הפונקציה צריכה להחזיר ערך, לא להדפיס.
▼ 🖥 אסטרטגיית Express — Q3
1

Setup בסיסי

express + json + cors + listen. אל תשכחו express.json()! בלי זה req.body ריק.

2

הגדרת data

מערך בזיכרון / חיבור MongoDB / קובץ — לפי הדרישה. הכינו נתוני דוגמה.

3

Routes אחד אחד

GET all → GET by id → POST create → PUT/PATCH update → DELETE. Status codes נכונים!

4

Filter route

אם יש סינון: POST /filter עם AND logic. כל פילטר שנשלח חייב להתקיים.

5

בדיקה

Postman / Thunder Client. בדקו כל route. שלחו body ריק — האם יש שגיאה ברורה?

Status 201 ליצירה, לא 200! appendFile ולא writeFile אם רוצים להוסיף לקובץ!
אם MongoDB: אל תשכחו { new: true, runValidators: true } ב-findByIdAndUpdate.
▼ 🚫 מפסידי נקודות — מה לא לעשות
  1. חסר key ב-map — React מתריע ב-console. הבודק מוריד על זה. השתמשו ב-id ייחודי, לא index.
  2. חסר express.json() — הguf של POST/PUT ריק. הכל נשבר בלי זה.
  3. ולידציות חלשות — בדקו כל שדה שנדרש. אל תסתפקו ב-"חובה" — בדקו regex, אורך, תבנית.
  4. localStorage לא מסונכרן — אם כתבתם setUsers אבל לא עשיתם useEffect לשמור — הנתונים נעלמים ברענון.
  5. console.log במקום return — ב-Q2 הפונקציה חייבת להחזיר, לא להדפיס.
  6. חסר cleanup ב-useEffect — setInterval / addEventListener בלי return () => clear... = memory leak.
  7. mutation של state — users.push(x) לא מעדכן React! צריך setUsers([...users, x])
  8. סינון OR במקום AND — ב-filter routes, כל התנאים צריכים להתקיים ביחד.
  9. חסר status code — 201 ליצירה, 404 ללא נמצא, 400 לולידציה.
  10. Math.abs חסר — ב-Q2 עם מספרים שליליים, String(-42).length = 3 (כולל ה-minus).

⚛️ React (Q1):

  • כל .map() יש key ייחודי (לא index)
  • useEffect עם interval → יש cleanup
  • localStorage: init מ-storage + sync ב-useEffect
  • ולידציות: regex + הודעת שגיאה inline לכל שדה
  • password === confirmPassword
  • navigate אחרי login/register מוצלח
  • כל component מייצא/מייבא נכון
  • BrowserRouter עוטף את Routes

📐 JavaScript (Q2):

  • הפונקציה מחזירה return ולא console.log
  • ולידציית קלט: Array.isArray, typeof
  • Math.abs למספרים שליליים
  • edge case: מערך ריק, ערך אחד, כפילויות

🖥 Express (Q3):

  • express.json() לפני כל ה-routes
  • status 201 ליצירה
  • try/catch סביב DB operations
  • res.json() ולא res.send() ל-JSON
  • filter = AND logic (כל התנאים ביחד)
  • אם MongoDB: { new: true } ב-update
