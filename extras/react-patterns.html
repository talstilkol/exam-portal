PART 1 — React Hooks Deep Dive
useState - ניהול State▼

שימוש בסיסי - מספר / מחרוזת

מחזיר מערך: [value, setter]. כל קריאה ל-setter גורמת ל-re-render.

const [count, setCount] = useState(0);
const [name, setName] = useState('');

return (
  <div>
    <p>{count}</p>
    <button onClick={() => setCount(count + 1)}>+1</button>
    <input value={name} onChange={e => setName(e.target.value)} />
  </div>
);

State של אובייקט

חייבים ליצור אובייקט חדש עם spread. אסור לשנות ישירות!

const [form, setForm] = useState({ name: '', email: '', age: 0 });

// עדכון שדה בודד - spread + override
const handleChange = (e) => {
  setForm({ ...form, [e.target.name]: e.target.value });
};

<input name="name" value={form.name} onChange={handleChange} />
<input name="email" value={form.email} onChange={handleChange} />

State של מערך - הוספה, מחיקה, עדכון

const [items, setItems] = useState([]);

// הוספה - spread + new item
setItems([...items, newItem]);

// מחיקה - filter
setItems(items.filter(item => item.id !== idToDelete));

// עדכון פריט ספציפי - map
setItems(items.map(item =>
  item.id === idToUpdate
    ? { ...item, name: 'new name' }
    : item
));

Functional Update - עדכון על בסיס ערך קודם

כשהערך החדש תלוי בקודם, תמיד להשתמש בפונקציה כדי למנוע בעיות של stale state.

// בעייתי - יכול לדלג על עדכונים
setCount(count + 1);

// נכון - מבטיח שהערך מעודכן
setCount(prev => prev + 1);

// גם עם מערכים:
setItems(prev => [...prev, newItem]);

Lazy Initialization - אתחול עצלן

אם החישוב הראשוני יקר, מעבירים פונקציה. היא תרוץ רק בפעם הראשונה.

// הפונקציה תרוץ רק ב-render הראשון
const [data, setData] = useState(() => {
  const saved = localStorage.getItem('myData');
  return saved ? JSON.parse(saved) : [];
});
⚠️ טעות נפוצה: Mutation ישיר vs Immutable Update
❌ לא נכון - Mutation ישיר
// React לא יעשה re-render!
form.name = 'Tal';
setForm(form);

items.push(newItem);
setItems(items);
✅ נכון - אובייקט/מערך חדש
setForm({ ...form, name: 'Tal' });

setItems([...items, newItem]);

React משווה references. אם מעבירים את אותו אובייקט - הוא לא יודע שמשהו השתנה!

💡 טיפ למבחן

ב-90% מהמבחנים: טופס = אובייקט state, רשימה = מערך state. תמיד spread כשמעדכנים. שם השדה name ב-input תואם לשם ב-state כדי לעשות [e.target.name].

useEffect - תופעות לוואי (Side Effects)▼

שימוש בסיסי

רץ אחרי כל render שבו ה-dependencies השתנו.

// רץ אחרי כל render
useEffect(() => {
  document.title = `Count: ${count}`;
});

// רץ רק כש-count משתנה
useEffect(() => {
  document.title = `Count: ${count}`;
}, [count]);

// רץ רק פעם אחת - mount
useEffect(() => {
  fetchData();
}, []);

Cleanup Function - ניקוי

הפונקציה שמוחזרת רצה לפני האפקט הבא או כש-component מת (unmount).

useEffect(() => {
  const id = setInterval(() => {
    setSeconds(prev => prev + 1);
  }, 1000);

  // cleanup - חייב לנקות intervals!
  return () => clearInterval(id);
}, []);

// Event listener
useEffect(() => {
  const handler = (e) => setKey(e.key);
  window.addEventListener('keydown', handler);
  return () => window.removeEventListener('keydown', handler);
}, []);

Fetching Data - דפוס שליפת נתונים

const [data, setData] = useState([]);
const [loading, setLoading] = useState(true);
const [error, setError] = useState(null);

useEffect(() => {
  const fetchData = async () => {
    try {
      setLoading(true);
      const res = await fetch('https://api.example.com/items');
      const json = await res.json();
      setData(json);
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };
  fetchData();
}, []);

if (loading) return <p>Loading...</p>;
if (error) return <p>Error: {error}</p>;
⚠️ טעות נפוצה: לולאה אינסופית
// ❌ לולאה אינסופית! אובייקט חדש כל render
useEffect(() => {
  setItems([...items, newItem]);  // זה גורם ל-re-render → effect רץ שוב → ...
}, [items]);

// ❌ שכחתם [] - רץ כל render!
useEffect(() => {
  fetch('...').then(r => r.json()).then(setData);
}); // ← אין deps! fetch אינסופי
⚠️ טעות נפוצה: שכחת cleanup

שכחת clearInterval או removeEventListener = memory leak + התנהגות לא צפויה.

💡 טיפ למבחן

כלל: מה שנכנס ל-deps? כל משתנה שמשתמשים בו בתוך ה-effect ומגיע מ-state/props.
אם רוצים לרוץ רק ב-mount: [] ריק.
אם רוצים לסנכרן ל-localStorage: [items].

useRef - הפניות ו-DOM▼

גישה ל-DOM

const inputRef = useRef(null);

const handleClick = () => {
  inputRef.current.focus();        // פוקוס על input
  inputRef.current.value = '';    // ניקוי (לא מומלץ - controlled עדיף)
};

return <input ref={inputRef} />;

ערך שלא גורם ל-re-render

שינוי .current לא גורם ל-render. מושלם לספירות, timers, ערכים קודמים.

const renderCount = useRef(0);

useEffect(() => {
  renderCount.current += 1;
  console.log(`Rendered ${renderCount.current} times`);
});

שמירת ערך קודם

const prevValue = useRef();

useEffect(() => {
  prevValue.current = count;  // מעדכן אחרי render
}, [count]);

// prevValue.current = הערך הקודם של count
💡 טיפ למבחן: useRef vs useState
  • useState - כשרוצים שהמסך יתעדכן כשהערך משתנה
  • useRef - כשרוצים לשמור ערך בלי לגרום ל-render (DOM, timer ID, ערך קודם)
useMemo - חישובים יקרים▼

שימוש בסיסי

מחשב ערך רק כשה-dependencies משתנים. חוסך חישוב מיותר בכל render.

const sortedItems = useMemo(() => {
  console.log('Sorting...'); // רץ רק כש-items משתנה
  return [...items].sort((a, b) => a.name.localeCompare(b.name));
}, [items]);

// סינון יקר
const filtered = useMemo(() => {
  return items.filter(item =>
    item.name.toLowerCase().includes(search.toLowerCase())
  );
}, [items, search]);
💡 טיפ למבחן

אל תשתמשו ב-useMemo על כל דבר. רק על חישובים שבאמת איטיים (מיון, סינון של רשימות גדולות). סינון של 10 פריטים? לא צריך useMemo. סינון של 10,000? כן.

useCallback - פונקציות ממומואיזות▼

מניעת re-render מיותר של ילדים

כל render יוצר פונקציה חדשה. useCallback שומר את אותה פונקציה כל עוד ה-deps לא השתנו.

// בלי useCallback - פונקציה חדשה כל render
const handleDelete = (id) => {
  setItems(prev => prev.filter(item => item.id !== id));
};

// עם useCallback - אותה reference
const handleDelete = useCallback((id) => {
  setItems(prev => prev.filter(item => item.id !== id));
}, []); // [] כי משתמשים ב-functional update

// עכשיו Child לא יעשה re-render מיותר
<Child onDelete={handleDelete} />
💡 טיפ למבחן

useCallback שימושי בעיקר כש:
1. מעבירים פונקציה כ-prop לקומפוננטה שעטופה ב-React.memo
2. הפונקציה היא dependency ב-useEffect

PART 2 — Common Exam Patterns (דפוסים חוזרים)
Login / Register Pattern▼
📋 Pattern: מערכת Login + Register מלאה

הדפוס הכי נפוץ במבחנים. כולל: טופס, ולידציה, שמירה ב-localStorage, ניווט.

// App.jsx - State ברמה העליונה
function App() {
  const [users, setUsers] = useState(() => {
    const saved = localStorage.getItem('users');
    return saved ? JSON.parse(saved) : [];
  });
  const [currentUser, setCurrentUser] = useState(null);

  // שמירה ל-localStorage
  useEffect(() => {
    localStorage.setItem('users', JSON.stringify(users));
  }, [users]);

  const handleRegister = (newUser) => {
    setUsers(prev => [...prev, newUser]);
  };

  const handleLogin = (username, password) => {
    const user = users.find(
      u => u.username === username && u.password === password
    );
    if (user) { setCurrentUser(user); return true; }
    return false;
  };

  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Login onLogin={handleLogin} />} />
        <Route path="/register" element={<Register onRegister={handleRegister} />} />
        <Route path="/home" element={<Home user={currentUser} />} />
      </Routes>
    </BrowserRouter>
  );
}

Login Component

function Login({ onLogin }) {
  const [username, setUsername] = useState('');
  const [password, setPassword] = useState('');
  const [error, setError] = useState('');
  const navigate = useNavigate();

  const handleSubmit = (e) => {
    e.preventDefault();
    if (onLogin(username, password)) {
      navigate('/home');
    } else {
      setError('שם משתמש או סיסמה שגויים');
    }
  };

  return (
    <form onSubmit={handleSubmit}>
      <input value={username}
        onChange={e => setUsername(e.target.value)}
        placeholder="Username" />
      <input type="password" value={password}
        onChange={e => setPassword(e.target.value)}
        placeholder="Password" />
      {error && <p style={{ color: 'red' }}>{error}</p>}
      <button type="submit">Login</button>
      <button onClick={() => navigate('/register')}>Register</button>
    </form>
  );
}

Register Component with Validation

function Register({ onRegister }) {
  const [form, setForm] = useState({
    username: '', password: '', confirmPass: '', email: ''
  });
  const [errors, setErrors] = useState({});
  const navigate = useNavigate();

  const validate = () => {
    const errs = {};
    if (!form.username || form.username.length < 4)
      errs.username = 'שם משתמש - מינימום 4 תווים';
    if (!/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[!@#$%^&*]).{8,20}$/.test(form.password))
      errs.password = 'סיסמה: 8-20 תווים, אות גדולה+קטנה+ספרה+תו מיוחד';
    if (form.password !== form.confirmPass)
      errs.confirmPass = 'הסיסמאות לא תואמות';
    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(form.email))
      errs.email = 'כתובת מייל לא תקינה';
    return errs;
  };

  const handleChange = (e) => {
    setForm({ ...form, [e.target.name]: e.target.value });
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    const errs = validate();
    setErrors(errs);
    if (Object.keys(errs).length === 0) {
      onRegister({ username: form.username, password: form.password,
                    email: form.email });
      navigate('/');
    }
  };

  return (
    <form onSubmit={handleSubmit}>
      <input name="username" value={form.username}
        onChange={handleChange} placeholder="Username" />
      {errors.username && <p className="error">{errors.username}</p>}

      <input name="password" type="password" value={form.password}
        onChange={handleChange} placeholder="Password" />
      {errors.password && <p className="error">{errors.password}</p>}

      <input name="confirmPass" type="password" value={form.confirmPass}
        onChange={handleChange} placeholder="Confirm Password" />
      {errors.confirmPass && <p className="error">{errors.confirmPass}</p>}

      <input name="email" value={form.email}
        onChange={handleChange} placeholder="Email" />
      {errors.email && <p className="error">{errors.email}</p>}

      <button type="submit">Register</button>
    </form>
  );
}
💡 טיפ למבחן

שימו לב לדפוס: errors = אובייקט ריק אם אין שגיאות.
בדיקה: Object.keys(errs).length === 0 = הכל תקין.
הצגה: {errors.fieldName && <p>...</p>} מתחת לכל שדה.

CRUD Table Pattern - טבלת נתונים▼
📋 Pattern: CRUD מלא - הוספה, עריכה, מחיקה, חיפוש

הדפוס השני בשכיחות. טבלה עם טופס הוספה/עריכה, כפתורי מחיקה, ושדה חיפוש.

function ItemsManager() {
  const [items, setItems] = useState([]);
  const [form, setForm] = useState({ name: '', price: '' });
  const [editId, setEditId] = useState(null);
  const [search, setSearch] = useState('');

  // ADD / UPDATE
  const handleSubmit = (e) => {
    e.preventDefault();
    if (editId) {
      // UPDATE - map and replace
      setItems(items.map(item =>
        item.id === editId
          ? { ...item, ...form }
          : item
      ));
      setEditId(null);
    } else {
      // ADD - spread + new
      setItems([...items, { ...form, id: Date.now() }]);
    }
    setForm({ name: '', price: '' }); // reset form
  };

  // DELETE
  const handleDelete = (id) => {
    setItems(items.filter(item => item.id !== id));
  };

  // EDIT - populate form
  const handleEdit = (item) => {
    setForm({ name: item.name, price: item.price });
    setEditId(item.id);
  };

  // FILTER
  const filtered = items.filter(item =>
    item.name.toLowerCase().includes(search.toLowerCase())
  );

  return (
    <div>
      <input placeholder="Search..." value={search}
        onChange={e => setSearch(e.target.value)} />

      <form onSubmit={handleSubmit}>
        <input name="name" value={form.name}
          onChange={e => setForm({...form, name: e.target.value})} />
        <input name="price" value={form.price}
          onChange={e => setForm({...form, price: e.target.value})} />
        <button>{editId ? 'Update' : 'Add'}</button>
      </form>

      <table>
        <thead><tr>
          <th>Name</th><th>Price</th><th>Actions</th>
        </tr></thead>
        <tbody>
          {filtered.map(item => (
            <tr key={item.id}>
              <td>{item.name}</td>
              <td>{item.price}</td>
              <td>
                <button onClick={() => handleEdit(item)}>Edit</button>
                <button onClick={() => handleDelete(item.id)}>Delete</button>
              </td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
}
💡 טיפ למבחן

key חייב להיות ייחודי. Date.now() פשוט ועובד. לעולם אל תשתמשו ב-index כ-key אם הרשימה משתנה!
editId מנהל את מצב העריכה. null = הוספה, ערך = עריכה.
filter עובד על הרשימה המקורית, לא משנה אותה.

localStorage Persistence Pattern▼
📋 Pattern: שמירה וטעינה מ-localStorage

דפוס קריטי: טעינה ב-useState (lazy init) + שמירה ב-useEffect.

// שלב 1: טעינה מ-localStorage (lazy initialization)
const [items, setItems] = useState(() => {
  const saved = localStorage.getItem('items');
  return saved ? JSON.parse(saved) : [];
});

// שלב 2: שמירה ל-localStorage כש-items משתנה
useEffect(() => {
  localStorage.setItem('items', JSON.stringify(items));
}, [items]);
⚠️ טעויות נפוצות
  • שכחת JSON.parse() בטעינה - מקבלים string במקום מערך
  • שכחת JSON.stringify() בשמירה - נשמר [object Object]
  • שימוש ב-key שונה בטעינה ובשמירה
  • שכחת בדיקת null (אם אין ערך שמור, getItem מחזיר null)

Custom Hook - שימוש חוזר

function useLocalStorage(key, initialValue) {
  const [value, setValue] = useState(() => {
    const saved = localStorage.getItem(key);
    return saved ? JSON.parse(saved) : initialValue;
  });

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);

  return [value, setValue];
}

// שימוש:
const [todos, setTodos] = useLocalStorage('todos', []);

📋 Pattern: הגדרת Router מלאה

כולל: Routes, Link, Navigate, Dynamic params, State passing.

Link vs useNavigate

Link - ניווט דקלרטיבי (HTML)
// קישור רגיל - המשתמש לוחץ
<Link to="/home">Go Home</Link>
<Link to={`/edit/${item.id}`}>Edit</Link>
useNavigate - ניווט פרוגרמטי (JS)
// ניווט מתוך קוד - אחרי פעולה
const navigate = useNavigate();
navigate('/home');
navigate(`/edit/${id}`);

העברת נתונים בין דפים

// דף 1 - שולח
navigate('/details', {
  state: { item: selectedItem, from: 'home' }
});

// דף 2 - מקבל
function Details() {
  const location = useLocation();
  const { item, from } = location.state || {};

  if (!item) return <p>No data</p>;
  return <h1>{item.name}</h1>;
}
💡 טיפ למבחן

3 דרכים להעביר נתונים בין דפים:
1. URL Params: /edit/:id + useParams() - מתאים ל-ID
2. State: navigate('/x', {state: ...}) + useLocation() - מתאים לאובייקט שלם
3. Lifting State: state ב-App, מועבר כ-props לכל Route

Form Validation Pattern - ולידציה▼
📋 Pattern: ולידציה מלאה עם הצגת שגיאות

ולידציה בזמן אמת (onChange) או בשליחה (onSubmit). שגיאות כאובייקט, הצגה מתחת לכל שדה.

ולידציה ב-Submit

const [form, setForm] = useState({
  username: '', password: '', email: '', phone: ''
});
const [errors, setErrors] = useState({});

  setErrors(newErrors);
};

איפה לשים State?

📋 כלל אצבע: State עולה למעלה
  • רק קומפוננטה אחת צריכה? → State מקומי באותה קומפוננטה
  • שתי קומפוננטות אחיות צריכות? → State בהורה המשותף (Lifting State Up)
  • כל האפליקציה צריכה? → State ב-App

Lifting State Up

// App - מחזיק את ה-state
function App() {
  const [items, setItems] = useState([]);

  const addItem = (item) => setItems(prev => [...prev, item]);
  const deleteItem = (id) => setItems(prev => prev.filter(i => i.id !== id));

  return (
    <>
      {/* מעביר callback למטה */}
      <AddForm onAdd={addItem} />
      {/* מעביר נתונים + callback */}
      <ItemList items={items} onDelete={deleteItem} />
    </>
  );
}

// AddForm - מקבל callback כ-prop
function AddForm({ onAdd }) {
  const [name, setName] = useState('');

  const handleSubmit = (e) => {
    e.preventDefault();
    onAdd({ id: Date.now(), name });
    setName('');
  };

  return (
    <form onSubmit={handleSubmit}>
      <input value={name} onChange={e => setName(e.target.value)} />
      <button>Add</button>
    </form>
  );
}

// ItemList - מקבל נתונים + callback
function ItemList({ items, onDelete }) {
  return (
    <ul>
      {items.map(item => (
        <li key={item.id}>
          {item.name}
          <button onClick={() => onDelete(item.id)}>X</button>
        </li>
      ))}
    </ul>
  );
}

PART 3 — Validation Regex Collection
Regex Collection - אוסף ביטויים רגולריים▼
📋 כל ה-Regex מ-9 מבחנים - טבלת עזר
שדה Regex Pattern הסבר
Email /^[^\s@]+@[^\s@]+\.[^\s@]+$/ text@text.text - no spaces, one @, one dot
Password (8-20, complex) /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[!@#$%^&*]).{8,20}$/ lowercase + uppercase + digit + special, 8-20 chars
Phone (10 digits) /^\d{10}$/ Exactly 10 digits
Car Number (7 digits) /^\d{7}$/ Exactly 7 digits
English Name (Capital) /^[A-Z][a-zA-Z]*(\s[A-Z][a-zA-Z]*)*$/ Each word starts with uppercase
Hebrew Name /^[֐-׿\s]+$/ Hebrew characters + spaces only
Username (4+) /^[a-zA-Z0-9]{4,}$/ Letters + digits, min 4 chars

פירוט Lookaheads בסיסמה

// (?=.*[a-z])  - חייב אות קטנה אחת לפחות
// (?=.*[A-Z])  - חייב אות גדולה אחת לפחות
// (?=.*\d)     - חייב ספרה אחת לפחות
// (?=.*[!@#$%^&*]) - חייב תו מיוחד אחד לפחות
// .{8,20}      - אורך 8-20 תווים

// דוגמאות תקינות: Ab1!abcd, Pass@123
// דוגמאות לא תקינות: abc (קצר, חסר), ABCD1234 (חסר קטנה+מיוחד)

פונקציית ולידציה שלמה עם כל ה-Regex

const validateForm = (form) => {
  const errors = {};

  if (!form.username || !/^[a-zA-Z0-9]{4,}$/.test(form.username))
    errors.username = 'שם משתמש: מינימום 4 תווים, אותיות ומספרים';

  if (!/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[!@#$%^&*]).{8,20}$/.test(form.password))
    errors.password = 'סיסמה: 8-20, גדולה+קטנה+ספרה+תו מיוחד';

  if (form.password !== form.confirmPassword)
    errors.confirmPassword = 'הסיסמאות לא תואמות';

  if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(form.email))
    errors.email = 'כתובת מייל לא תקינה';

  if (form.phone && !/^\d{10}$/.test(form.phone))
    errors.phone = 'טלפון: בדיוק 10 ספרות';

  if (form.carNumber && !/^\d{7}$/.test(form.carNumber))
    errors.carNumber = 'מספר רכב: בדיוק 7 ספרות';

  if (form.engName && !/^[A-Z][a-zA-Z]*(\s[A-Z][a-zA-Z]*)*$/.test(form.engName))
    errors.engName = 'שם באנגלית: כל מילה מתחילה באות גדולה';

  if (form.hebName && !/^[֐-׿\s]+$/.test(form.hebName))
    errors.hebName = 'שם בעברית: אותיות עבריות בלבד';

  return errors;
};

💡 טיפ למבחן

1. תמיד ^ בתחילה ו-$ בסוף (תפיסת כל המחרוזת)
2. ?= = Lookahead (חייב להכיל, בלי לצרוך)
3. {n} = בדיוק n, {n,} = n ומעלה, {n,m} = בין n ל-m
4. \d = ספרה, [a-zA-Z] = אותיות, [^\s@] = לא רווח ולא @

⚠️ טעות נפוצה ב-Regex
  • שכחת ^ ו-$ - "abc123!@#" יתאים ל-regex של סיסמה גם אם יש תווים נוספים
  • שימוש ב-match() במקום test() - test מחזיר boolean, match מחזיר מערך
  • שכחת escape לתווים מיוחדים ב-Regex: . צריך \. אם רוצים נקודה ממש

Context API — שיתוף state בלי prop drilling

כשצריך להעביר נתונים לcomponents עמוקים בעץ, Context חוסך העברת props דרך כל שכבה:

// 1. יצירת Context
import { createContext, useContext, useState } from 'react';

const AuthContext = createContext(null);

// 2. Provider component
function AuthProvider({ children }) {
  const [user, setUser] = useState(null);

  const login = (userData) => setUser(userData);
  const logout = () => setUser(null);

  return (
    <AuthContext.Provider value={{ user, login, logout }}>
      {children}
    </AuthContext.Provider>
  );
}

// 3. Custom hook לשימוש נוח
function useAuth() {
  return useContext(AuthContext);
}

// 4. שימוש ב-App
function App() {
  return (
    <AuthProvider>
      <Header />
      <Routes>...</Routes>
    </AuthProvider>
  );
}

// 5. שימוש ב-component עמוק
function Header() {
  const { user, logout } = useAuth();
  return <div>{user ? user.name : 'Guest'}</div>;
}
מתי Context ומתי Props?
Props — נתון שעובר 1-2 רמות, או נתון ייחודי לcomponent.
Context — נתון גלובלי (user, theme, language) שהרבה components צריכים.
